# 🎮 真机实验室

> **在你浏览器里真机跑 OpenCV 算法**——不用装 OpenCV、不用写代码、不用上传图片到任何服务器。底层是 OpenCV.js（WebAssembly 版 OpenCV），**全部计算在你电脑/手机本地完成**。

## 玩法

1. 左边选一张**内置示例图**（13 种常见场景：街景/人脸/行人/棋盘格/硬币/文档/纹理/水果/连续帧…），或点「📂 上传图片」用自己的照片；
2. 中间选**算法**（39 种，覆盖六大分支），拖动滑块调参数，结果会实时刷新；
3. 右边看到**处理结果**和**毫秒级耗时**；
4. 每个算法下方自动生成**实时联动的 Python / C++ / JavaScript 代码**，拖参数时代码里的参数值同步更新——可以直接复制到自己项目里。

## 🎬 视频 / 时序算法（要上传视频？看这里）

上面这个工作台处理的是**单张图片**。但下面这几个算法**天生依赖"帧与帧之间"的变化**，拿一张静止图片根本演示不出来——所以它们有专门的**视频真机实验**：左边原视频、右边逐帧处理结果，可换算法、拖滑块、**上传你自己的视频**。

| 算法 | 看什么 | 上去玩 |
|---|---|---|
| **LK 稀疏光流（KLT）** | 几百个特征点逐帧"追过去"，绿线是运动矢量 | [lucas-kanade](/algorithms/lucas-kanade/) |
| **Farnebäck 稠密光流** | 每个像素都有运动矢量，颜色表示运动方向 | [farneback](/algorithms/farneback/) |
| **MOG2 背景减除** | 每个像素维护高斯分布，长期不变的就是背景 | [mog2](/algorithms/mog2/) |
| **帧差法** | 相邻两帧相减 + 阈值，最快最简单的运动检测 | [mog2](/algorithms/mog2/)（切换算法） |
| **MeanShift 目标跟踪** | 颜色直方图反向投影 + 窗口往"最像目标"的方向挪 | [meanshift](/algorithms/meanshift/) |
| **CamShift 自适应跟踪** | 窗口大小和旋转角都跟着目标变 | [camshift](/algorithms/camshift/) |

> 🧓 **一句话区分**：光流是"**点/像素**在动"，背景减除是"**这块地方**变了"，目标跟踪是"**这个东西**跑到哪了"。
>
> 💡 光流类算法在视频上跑起来后，你会看到**运动方向上真的在流**——这是静态图永远给不了的直觉。

## 为什么有两个"实验室"？

| | 🧪 原理实验室 | 🎮 真机实验室（本页） |
|---|---|---|
| **目标** | 搞懂"为什么"——数学原理 | 看见"什么样"——真算法效果 |
| **数据** | 合成小图（几个点/一条线） | 真实照片 |
| **依赖** | 纯 Canvas，**秒开**，不用下载任何东西 | OpenCV.js（约 11 MB，首次加载需几秒） |
| **代码** | 没有代码，只有数学直观 | 实时生成 Python/C++/JS 代码可复制 |
| **建议顺序** | 🟢 小白先看这里 | 原理懂了再来这里跑 |
| **对应关系** | 14 个原理 tab ↔ 本页 39 个算法 | 每个算法页底部也有同款实验室 |
| **视频算法** | 含光流 / 背景减除的数学原理 tab | 6 个**视频真机实验**，可上传自己的视频 |
