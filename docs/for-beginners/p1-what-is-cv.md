# 第 1 页 · 计算机视觉在做什么

**一句话**：让计算机从"一张由数字组成的图"里，看懂"这是什么、在哪里、有什么结构"。

## 一张图在计算机眼里是什么？

想象一张 1920×1080 的彩色照片，在计算机里就是一个**大数组**：

- 它被切成 1920 × 1080 = **2,073,600** 个小格子，每个格子叫一个**像素（pixel）**
- 每个像素有**三个通道**：R（红）、G（绿）、B（蓝），每个值都是 0–255 的整数
  - `(255, 255, 255)` = 纯白
  - `(0, 0, 0)` = 纯黑
  - `(255, 0, 0)` = 纯红
- 所以一张彩色照片 = 一个 **1080 × 1920 × 3 ≈ 620 万个数字**的矩阵

**灰度图**更简单——每个像素只有一个数（0–255），0 黑 255 白。传统 CV 算法里 90% 先把彩色转成灰度再处理，因为颜色通常不是关键信息，**明暗变化才是**。

```python
import cv2
img = cv2.imread("cat.jpg")          # shape: (1080, 1920, 3)，BGR 顺序
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)  # shape: (1080, 1920)，单通道
print(gray[200, 300])                 # 输出一个 0-255 的整数
```

## 三个必须知道的基础词

传统 CV 的所有算法，本质上都在操作这三样东西：

### 1️⃣ 像素值（pixel value）
就是那个 0–255 的数字。图像**越亮**的地方像素值越大，**越暗**越小。看像素值的变化，就知道"这里有条边"——因为从亮到暗跳变的地方，就是物体的轮廓。

### 2️⃣ 梯度（gradient）
"相邻两个像素差多少"。**梯度大 = 颜色跳变快 = 很可能是边缘**。Canny、Sobel 这些"边缘检测"算法，本质就是算梯度、挑大的地方。

> 生活比喻：你在平地上走路，地面高度就是像素值；梯度就是坡度。坡度突然变陡的地方，就是"悬崖"——对应图像里的边缘。

### 3️⃣ 邻域 / 窗口（neighborhood / window）
"以当前像素为中心的一个小方块"，比如 3×3、5×5、7×7。
- 想知道"这个点是不是边缘"，不能只看自己，得看周围一圈——这就是为什么几乎所有算法都要"开一个 3×3 的窗口扫一遍"
- 想找"角点"（比如桌子角），要看窗口移动时，**不管往哪个方向挪，窗口里的像素变化都很大**——这是 Harris 角点的核心直觉

> 生活比喻：判断你是不是站在十字路口，不能只看你脚下的地砖，得看周围一圈有没有四个方向的路。

## 传统 CV 的核心信念：**特征（Feature）**

深度学习是"给图进神经网络，网络自己学出特征"。
**传统 CV 的思路完全相反**：工程师**手工设计**一种"好认的标志"（= 特征），然后让算法去图里找。

- 找边缘？→ **梯度大的地方**（Canny）
- 找角点？→ **窗口往任何方向挪都大变的地方**（Harris）
- 找斑点？→ **周围一圈比中间亮/暗的地方**（LoG/DoG）
- 找可以用来匹配的关键点？→ **不管旋转/缩放/亮暗都能重复找到的点**（SIFT）
- 找整个人？→ **身体形状的梯度方向直方图**（HOG + SVM）

> 这就是为什么传统 CV 又叫"hand-crafted features（手工特征）"——不是机器学的，是人根据几何、物理、统计规律**设计出来**的。优点是可解释、不依赖训练数据、CPU 上就跑；缺点是每个任务要单独设计特征，泛化性不如深度学习。

## 三个贯穿始终的"工具动作"

所有传统 CV 算法，再复杂，底层都是这三个动作反复组合：

| 动作 | 一句话 | 例子 |
|---|---|---|
| **卷积（convolution）** | 拿一个小矩阵（叫核/kernel）在图上滑，每个位置做点积 | 高斯模糊、Sobel 算梯度、LoG 找斑点 |
| **阈值化（threshold）** | 像素值 > 某个数设成白，否则设成黑（二值化） | Otsu 自动找阈值、Canny 双阈值 |
| **非极大值抑制（NMS）** | 在一堆候选里只留"最像那个"的，压掉重复的 | Canny 细边、HOG 检测后去重框 |

记不住名字？没关系——你只需要知道：**"滑一个小方块做点积 → 设个门槛挑大的 → 重复的压掉"**，这三件事串起来就是传统 CV 90% 的算法骨架。

## 你现在能做什么

读完这一页，你已经懂了：
- ✅ 图在计算机里就是数字矩阵
- ✅ 传统 CV 的核心是"人手设计特征"，不是"让机器学"
- ✅ 卷积 / 阈值 / NMS 是三大底层动作
