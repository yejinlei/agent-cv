# 🐣 小白入门 · 5 页看懂传统 CV

你是刚入门的 CV 小白，或者被深度学习大潮冲过来想回头补基础的工程师？这一页给你一条**最短的阅读路径**。跟着五段走下来，你能看懂后面任何一个算法的 index 页，也能在工作中判断"这个场景该不该用传统 CV"。

**前置要求**：高中数学 + Python 语法基础 + 能看懂"像素是一个 0–255 的数字"。
**不要**先翻[术语表](/glossary)——那本词典适合"已经入门想查某词"的时候用。

## 这一页不是教你什么

- ❌ 不教 OpenCV 怎么装（那是安装文档的事）
- ❌ 不推公式（公式都放在每个算法的 `concepts.md` 里，有需要再翻）
- ❌ 不做深度学习对比踩一捧一（传统 CV 不是"过时"，是"在合适的场景还在用"）
- ❌ 不讲最新论文（传统 CV 的核心算法 2012 年之前就定型了，越老越值钱）

## 读完你能做什么

- 在工位上看到一张带光照不均的零件图，能判断「先开卷积 → 再二值化 → 再连通域」的顺序
- 看别人代码里的 `cv2.Canny(img, 50, 150)` 知道两个阈值在干嘛、调大调小会怎样
- 知道"特征点"不是什么玄学，SIFT/ORB 就是在找"不管怎么转怎么缩都能认出来的小斑块"
- 面对一个新项目，能在 10 分钟内给出「传统 CV 方案 vs 深度学习方案」的选型建议
