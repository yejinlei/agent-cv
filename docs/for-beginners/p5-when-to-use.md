# 第 5 页 · 什么时候选传统 CV，什么时候上深度学习

这是最现实的问题。读完前四页你会发现"传统 CV 好厉害"，但现实是 2026 年大部分 CV 工作都用深度学习了——**不是传统 CV 不行，是要看场景**。这一页给你一张决策表。

## 一张决策表：该不该用传统 CV

| 判断维度 | 倾向传统 CV | 倾向深度学习 |
|---|---|---|
| **算力** | 只有 CPU / 单片机 / ARM 边缘端（树莓派、K210、STM32）| 有 GPU/NPU（Jetson、NVIDIA GPU、端侧 NPU）|
| **数据量** | 没有标注数据，或者很难标（工业缺陷、罕见样本）| 有 ≥1000 张标注数据，且还能继续采 |
| **任务明确度** | 任务极明确（找圆、量尺寸、数个数、OCR 定区域）| 类别多、变化大（猫狗人车型 80 类）|
| **可解释性** | 出错必须解释为什么（医疗、安全、工业质检）| 黑盒可接受（推荐、内容审核有复核）|
| **延迟要求** | 毫秒级甚至微秒级（产线高速运动）| 百毫秒级可接受（手机、视频流）|
| **光照/视角** | 环境可控（工业光源、固定相机）| 开放环境（街拍、手机随手拍）|
| **开发周期** | 几天到两周出原型 | 要数据采集 + 标注 + 训练 ≥1 个月 |
| **维护成本** | 规则可控，参数调完几年不动 | 场景变了要重训，模型要迭代 |

> **核心判断**：**环境可控 + 任务单一 + 算力受限 + 要求可解释** → 传统 CV。**开放场景 + 多类别 + 数据充足 + 有 GPU** → 深度学习。

## 六个真实场景的选型

### ✅ 场景 1：工业产线上数螺丝个数

- **条件**：固定相机 + 环形光源 + 传送带匀速 + 螺丝形状固定
- **选型**：**传统 CV 完胜**——二值化 + 形态学开运算 + 连通域计数，OpenCV 10 行代码，CPU 毫秒级，100% 准确率
- **不要**用 YOLO——杀鸡用牛刀，而且没有一万个标注样本根本训不稳

### ✅ 场景 2：测量零件尺寸（精度 0.01mm）

- **条件**：远心镜头 + 背光照明 + 零件在画面里
- **选型**：**传统 CV 完胜**——Canny 亚像素边缘 + 卡尺测量 / 霍夫变换拟合直线圆，精度能到 0.01 像素
- **不要**用深度学习——回归尺寸的 CNN 精度达不到工业计量级

### ⚠️ 场景 3：厂区监控里检测有没有人闯入

- **条件**：固定摄像头 + 光照变化大 + 白天黑夜 + 可能穿各种衣服
- **选型**：**深度学习更好**（YOLOv8n）——HOG+SVM 在夜间、逆光、穿大衣时召回率掉得厉害
- **如果算力极度受限**：可以试背景建模（MOG2）+ HOG 验证，这是传统 CV 能做的极限

### ✅ 场景 4：车牌识别（小区门禁）

- **条件**：固定相机 + 道闸位置固定 + 车牌大小位置大致可预测 + 中国蓝牌
- **选型**：**传统 CV 方案仍然主流**——颜色定位蓝牌区域 + Sobel 垂直边缘精定位 + 字符分割 + 模板匹配/SVM 识别字符。速度快、无需 GPU、在固定场景下 99%+ 识别率
- **开放道路/新能源绿牌/污损**：用深度学习

### ✅ 场景 5：文档扫描/矫正（类似 CamScanner）

- **条件**：手机拍文档，自动找四边形、矫正透视
- **选型**：**传统 CV 至今仍是标准方案**——边缘检测 + 霍夫直线 + 找最大四边形 + 透视变换。微软 Lens、CamScanner、苹果备忘录扫描 全是这套
- **深度学习**可以做辅助（比如去阴影、增强），但核心的"找纸"动作还是传统 CV

### ❌ 场景 6：城市道路目标检测（自动驾驶）

- **条件**：车外、多类别（人车非机动车交通灯交通标志）+ 雨雪雾夜晚
- **选型**：**必须深度学习**——传统 CV 根本应付不了开放场景 80+ 类的检测，YOLO/BEVFormer 这种才够
- 传统 CV 只在里面做辅助（比如车道线检测还能用霍夫变换兜底）

## 传统 CV 和深度学习的结合方式（"现代工程做法"）

实际工程里两者不是二选一，而是**常常用在一起**：

| 组合方式 | 例子 |
|---|---|
| **传统 CV 做前处理** | 用 Canny/形态学找到 ROI 区域，再送进 CNN 分类；比"整张图进 CNN"快得多 |
| **传统 CV 做后处理** | YOLO 检出框后，用 NMS（传统算法！）去重；分割网络输出后用连通域统计个数 |
| **传统 CV 当兜底** | 深度学习在低置信度时 fallback 到传统算法（如 OCR 里 CNN 识别 + 模板匹配兜底）|
| **传统 CV 生成数据** | 用 OpenCV 渲染大量合成数据（旋转、缩放、加噪声）来训练神经网络 |
| **深度学习代替传统某一步** | 用一个小 CNN 代替 Canny 做边缘检测（DexiNed），但后处理仍用传统 NMS/霍夫 |

## 五条新手避坑建议

1. **别上来就上 YOLO**。很多新手拿到任务第一反应是找 YOLO 权重，但工业里 80% 的小任务 OpenCV 就能解决，**先试试传统方案，半小时能出原型再说**。
2. **先控光，再写算法**。传统 CV 效果差 90% 的原因不是算法不行，是光源没打好、相机没固定。先把"光+相机+位置"固定住，算法会简单 10 倍。
3. **不要调参调到死**。如果一个 Canny 阈值调了一天还不理想，说明问题不在参数——回去看光源、看镜头、看背景是不是干净。
4. **先做原型验证可行性**。不管传统还是深度学习，先用半小时做个最小原型（哪怕是 Jupyter Notebook），看方向对不对再投入。
5. **保留传统 CV 的知识**。2026 年很多大厂面试仍然考 SIFT/Canny/Hough/RANSAC 的原理，因为这是理解计算机视觉的基本功。即使你天天用 YOLO，这些底层原理也会让你用得更明白。
