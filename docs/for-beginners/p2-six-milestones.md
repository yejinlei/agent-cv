# 第 2 页 · 六个关键转折：从边缘到识别

把传统 CV 的 50 年当成一条**演化链**，每个里程碑只记"上一版的一个痛点 + 本版如何解决"。

## 六个里程碑总表

| 代 | 年份 | 算法 | 一句话概括 | 解决了什么痛点 |
|---|---|---|---|---|
| **①** | 1963 | Roberts 边缘算子 | 用 2×2 差分找边缘 | 计算机连"物体在哪"都不会 |
| **②** | 1986 | Canny 边缘检测 | 多阶段：平滑 → 梯度 → NMS → 双阈值 | 简单差分噪声太多、边太粗 |
| **③** | 1988 | Harris 角点 | 窗口四处挪动都变化大的点 = 角点 | 只找到边，找不到"可以拿来匹配"的点 |
| **④** | 1999/2004 | SIFT 特征点 | 尺度不变 + 旋转不变 + 128 维描述子 | Harris 不抗缩放、不抗旋转，没法跨图匹配 |
| **⑤** | 2001 | Viola-Jones 人脸检测 | Haar 特征 + 积分图 + AdaBoost 级联 | 人脸检测需要实时，之前的方法太慢 |
| **⑥** | 2005 | HOG + SVM 行人检测 | 梯度方向直方图 + 支持向量机整人检测 | Haar 太简单，行人这种形状复杂的物体搞不定 |

> 记不住没关系，只记**一条主线**：边缘（Canny）→ 角点（Harris）→ 不变特征点（SIFT）→ 快速检测（V-J）→ 形状统计 + 分类器（HOG+SVM）。这就是传统 CV 从"看像素"到"认物体"的六步走。

## ① 1963 · Roberts 算子：计算机开始"看边"

**痛点**：在那之前计算机只能看每个像素多亮，不知道"物体轮廓在哪"。

**解法**：Larry Roberts 想到——如果一个像素和右边、下边的像素差很多，说明这里有"边界"。他用 2×2 的差分：

```
[+1  0]
[0  -1]
```

这是人类第一个"边缘检测"算子。**粗糙，但打开了一扇门**——原来不直接看像素值，而是看像素差，就能找到物体轮廓。

**缺点**：对噪声极度敏感——一个噪点就会被当成边。

## ② 1986 · Canny：把"找边"做成流水线

**痛点**：Roberts/Sobel 这些算子找到的边**粗、散、乱**，同一个边会被检出好几条像素宽，而且噪声多时会出一堆假边。

**解法**：John Canny 在麻省理工写了篇硕士论文，把"找边"拆成**四步流水线**：

1. **先模糊**（高斯滤波）——噪声压掉
2. **算梯度**（Sobel）——找到"哪里有跳变"
3. **非极大值抑制**（NMS）——粗边变细边，只留最亮的那个像素
4. **双阈值 + 滞后跟踪**——强边直接留、弱边必须连着强边才留，孤立弱边是噪声压掉

> 生活比喻：你在黑夜找路——① 先戴眼镜看清（模糊去噪）；② 看到光条（梯度）；③ 只走路中间最亮的那一条（NMS）；④ 大路直接走，小路只有接在大路上才走（双阈值）。

**为什么划时代**：Canny 1986 年提出后，到 2026 年的今天**还是工业界边缘检测的默认选择**——40 年没人超越它的"效果+速度"平衡。OpenCV 的 `cv2.Canny()` 一行就调完。

## ③ 1988 · Harris 角点：从"边"到"点"

**痛点**：边缘是"一条线"，没法拿来做"这两张图里的是不是同一个地方"——因为一条边上有无数个点看起来都一样。

**解法**：Chris Harris & Mike Stephens 想——如果以一个点为中心开个小窗口，把窗口往各个方向挪一小段：
- 往任何方向挪窗口里的像素都**几乎不变** → 这是**平原**（没用）
- 只在**一个方向**挪会变 → 这是**边**（还是没法唯一确定位置）
- 往**任何方向**挪都会大变 → 这是**角**！（就是它了）

用一个 2×2 的矩阵 M（结构张量）就能数学上判断这个点属于三类里的哪一类。

**为什么重要**：Harris 是第一个可以稳定重复找到的"兴趣点"——同一场景拍两次，Harris 能在同一个物理位置检出点，这就打开了"图像匹配"的大门。

## ④ 2004 · SIFT：尺度旋转都不怕的"指纹点"

**痛点**：Harris 角点有个致命问题——**缩放一下、转个角度**就找不到了。相机往后退两步（物体变小），同一个角点就再也检不出来，完全没法做"大场景拼图"或"物体识别"。

**解法**：David Lowe 用了五年磨一剑（1999 初版、2004 定稿），SIFT（Scale-Invariant Feature Transform）做了**四件大事**：

1. **尺度空间极值检测**：用不同大小的高斯核模糊（= 远近不同），找在"不管大小怎么变"都是局部最亮/最暗的点——抗缩放
2. **关键点定位**：精修位置，去掉边缘响应点
3. **方向赋值**：给每个关键点算一个主方向——抗旋转
4. **128 维描述子**：把关键点周围分成 4×4 的小格，每格算 8 个方向的梯度直方图，一共 4×4×8 = **128 个数**——这就是这个点的"数字指纹"

> 生活比喻：SIFT 点就像你认人——不管他站远站近（尺度不变）、脸正脸侧（旋转不变）、灯亮灯暗（光照鲁棒），你都能认出来，因为你看的不是像素，而是"五官相对关系"（=128 维描述子）。

**为什么划时代**：SIFT 是第一个真正"工业可用"的局部特征，直接催生了图像拼接（全景）、三维重建、物体识别、图像检索整个领域。后来 SURF、ORB、BRISK 全是它的变体。专利到期后更是无处不在。

深入跳：[SIFT 档案](/algorithms/sift/)

## ⑤ 2001 · Viola-Jones：第一次实时人脸检测

**痛点**：在那之前人脸检测要几秒一张图，根本做不到相机取景框里实时画框。

**解法**：Paul Viola 和 Michael Jones 用了**三招组合拳**：

1. **Haar-like 特征**：不用像素本身，用"相邻矩形的像素和之差"——比如眼睛比脸颊暗、鼻梁比两侧亮
2. **积分图（Integral Image）**：一个天才的数据结构，让任何矩形的像素和都能 **4 次查表**算完——Haar 特征瞬间变快
3. **AdaBoost 级联分类器**：先用几个简单特征快速筛掉 99% 的非人脸窗口，难的窗口再用更多特征细判——像"漏斗"，大部分窗口在第一关就被毙掉

**效果**：在 2001 年的 700MHz Pentium III 上跑 **30 FPS 实时人脸检测**——这是 CV 历史上第一次"实时检测人脸"，直接催生了数码相机的笑脸快门、早期人脸解锁。

**局限**：Haar 特征太简单，只能检"形状刚性"的东西（正脸），侧脸、歪头都不行。检测行人时几乎瞎——这就引出了下一代。

深入跳：[Viola-Jones 档案](/branches/detection/viola-jones)

## ⑥ 2005 · HOG + SVM：行人检测的基石

**痛点**：行人不是正脸，形状比人脸复杂得多——Haar 这种"矩形差"描述不了"轮廓梯度的形状"。

**解法**：Navneet Dalal 和 Bill Triggs（INRIA）提出 HOG（Histogram of Oriented Gradients，方向梯度直方图）：

1. 把检测窗口切成 8×8 的 **cell**，每个 cell 算 9 个方向的梯度直方图
2. 把 2×2 个 cell 合成一个 **block**，对 block 内的直方图做归一化——抗光照
3. 整个检测窗口（64×128）所有 block 的直方图拼起来 = **3780 维**的特征向量
4. 送进一个**线性 SVM**（支持向量机）做二分类："这是行人 / 不是行人"

**为什么划时代**：HOG+SVM 把"形状统计 + 判别分类器"这条路走通了——从此"滑窗 + 手工特征 + 分类器"成了传统目标检测的标准范式，DPM（可变形部件模型）就是它的升级版。

这是**深度学习登场前最后一代主流检测方案**。2012 年 AlexNet 横空出世后，手工特征这条线逐渐让位于 CNN，但 HOG/SIFT/Canny 至今在工业界有大量应用。

## 六个里程碑看完，你已经能回答

- ✅ 为什么 Canny 40 年没过时？——因为它是多阶段流水线，每一步都工程打磨到了极致
- ✅ 为什么 Harris 到 SIFT 跨了 16 年？——"尺度+旋转不变"是极其难的问题，Lowe 磨了 5 年
- ✅ 为什么传统检测一定要"滑窗"？——在 CNN 出现之前，不知道物体在哪，只能每一个位置都试一遍
- ✅ 为什么说传统 CV 不是被淘汰，是"在合适场景还在用"？——低算力、可解释、无需训练数据的场景下，这些算法 2026 年还在产品里
