## 第 1 页 · 传统计算机视觉到底在做什么

输入：一张像素矩阵（比如 640×480 的 uint8 数组）
输出：

```python
[
  {"task": "边缘",   "result": "像素级二值图，1=边缘"},
  {"task": "角点",   "result": "[(x,y), (x,y), ...] 关键点坐标"},
  {"task": "分割",   "result": "像素级类别图"},
  {"task": "匹配",   "result": "[(src_pt, dst_pt), ...] 对应关系"},
  {"task": "检测",   "result": "[(x1,y1,x2,y2,class,score), ...]"},
  {"task": "三维",   "result": "深度图 / 相机位姿 / 点云"}
]
```

**一句话理解**：传统 CV 就是"人告诉计算机该找什么特征"——边缘找梯度大的地方、角点找两个方向都变化的点、匹配靠描述子相似度。它跟深度学习的根本差别是：**特征是人设计的，不是学出来的**。

## 第 2 页 · 经典算法的六个关键转折

| 年代 | 算法 | 一句话概括 | 解决了上一版的什么痛点 |
|---|---|---|---|
| 1963 | **Sobel** | 用 3×3 卷积核算梯度找边缘 | 纯差分抗噪差，Sobel 加了高斯平滑 |
| 1979 | **Otsu 大津法** | 自动算二值化阈值，不用手动试 | 阈值分割全靠肉眼调，没有客观标准 |
| 1986 | **Canny** | 三阶段（平滑→梯度→NMS+双阈值）把边缘变成"单像素细线" | Sobel 出来的边粗、有噪声响应、断点多 |
| 1988 | **Harris 角点** | 用自相关矩阵的两个特征值判断角点 | Moravec 对方向敏感、不抗噪 |
| 2001 | **Viola-Jones** | 积分图 + AdaBoost 级联，做到"实时人脸检测" | 滑窗 + SVM 算一遍要几秒，工业不能用 |
| 2004 | **SIFT** | 尺度空间 DoG + 128 维描述子，缩放旋转都能匹配 | Harris 不具备尺度不变性，图像缩了就匹配不上 |
| 2005 | **HOG+SVM** | 梯度方向直方图 + SVM，行人检测标配 | Haar 特征对刚性物体差，行人需要形状信息 |
| 2006 | **SURF** | 用 Hessian 近似 + 积分图加速 SIFT | SIFT 太慢，实时场景跑不动 |
| 2008 | **DPM** | 可变形部件模型，处理物体形变 | HOG+SVM 是刚性模板，人一弯腰就检不出来 |
| 2011 | **ORB** | 带方向的 FAST 角点 + BRIEF 描述子，二进制、极快 | SIFT/SURF 有专利，ORB 开源免费还能跑在手机上 |

## 第 3 页 · Canny 拆解（入门样板，必读）

Canny 是整个传统 CV 入门的「Hello World」，搞懂它再学别的会顺很多。

```
输入灰度图
  ↓
① 高斯模糊：用 5×5 高斯核把噪声抹平（"拍照前先戴近视眼镜"）
  ↓
② Sobel 算梯度：每个像素得到 (Gx, Gy)，再算幅值 G 和方向 θ
  ↓
③ 非极大值抑制（NMS）：沿梯度方向只保留局部最大那个像素 → 边从"粗带"变"细线"
  ↓
④ 双阈值：高阈值 T_high（强边缘，必留）/ 低阈值 T_low（弱边缘，看邻居）
  ↓
⑤ 滞后追踪：弱边缘如果旁边连着强边缘就留，否则当噪声扔掉
  ↓
输出：单像素宽的干净边缘图
```

**为什么 Canny 是工业界 40 年常青树？**
- 只有 3 个参数（高斯核 σ、T_high、T_low），好调
- 步骤完全可解释，出问题能精准定位到哪一步
- CPU 就能跑，640×480 图 < 1ms

## 第 4 页 · 其他经典算法各记一句

| 算法 | 年代 | 只做一件事 | 一句吐槽 |
|---|---|---|---|
| Sobel | 1968 | 3×3 核算 x/y 方向梯度 | "边缘检测的祖宗，所有后来者都在用它" |
| Otsu | 1979 | 类间方差最大 → 自动阈值 | "二值化不用手调，强迫症福音" |
| Harris | 1988 | 自相关矩阵两个特征值都大 = 角点 | "数学最漂亮的角点，就是对尺度敏感" |
| Viola-Jones | 2001 | 积分图 + AdaBoost 级联 → 实时人脸 | "第一次让人脸检测跑进相机，OpenCV 自带" |
| SIFT | 2004 | DoG 关键点 + 128 维描述子 | "最稳的特征点，唯一缺点是慢、以前有专利" |
| HOG+SVM | 2005 | 梯度方向直方图 + 线性 SVM | "行人检测打了十年工，直到深度学习才下岗" |
| SURF | 2006 | Hessian 近似 + 积分图加速 SIFT | "号称 SIFT 的 3 倍速，专利也更严" |
| DPM | 2008 | 根模板 + 部件模板 + 形变代价 | "传统检测的巅峰，也是传统检测的绝唱" |
| ORB | 2011 | oFAST + rBRIEF 二进制描述子 | "免费、快、够用，SLAM 界标配到今天" |
| RANSAC | 1981 | 随机采样一致，剔除外点 | "所有几何视觉问题的橡皮，擦掉错匹配" |
| Lucas-Kanade | 1981 | 光流跟踪：相邻帧小位移假设 | "跟踪一个点的运动，KLT 追踪器就是它" |
| 张氏标定 | 2000 | 拍几张棋盘格就能标定相机 | "相机标定的傻瓜方案，OpenCV 一行函数" |

## 第 5 页 · 你该做什么？（按场景选路）

| 场景 | 起点 | 建议学到哪 |
|---|---|---|
| 🎓 **零基础入门** | 读 Canny → Sobel → Otsu → Harris → SIFT | 停在 SIFT，理解「特征是怎么被设计出来的」 |
| 🏭 **工业缺陷检测** | 直接看图像处理 + 阈值分割 + 形态学 | 不用学 SIFT/DPM，Otsu + 形态学 + 轮廓就够 80% |
| 📱 **手机/嵌入式部署** | 读 Canny → ORB → Viola-Jones | 停在 ORB，二进制描述子 + 级联分类器都能在 ARM 上实时 |
| 🤖 **视觉 SLAM / 三维重建** | Harris → SIFT → 对极几何 → 立体匹配 → RANSAC | 必学 Lucas-Kanade 光流 + 张氏标定 + 八点法 |
| 📄 **OCR / 文档处理** | 二值化 + 形态学 + 投影 + 轮廓 + Hough 变换 | 不用学 SIFT/DPM，霍夫变换找直线更关键 |
| 🚗 **自动驾驶 / 行人检测** | HOG+SVM → DPM → 再读 YOLO 入门 | 传统方法学完 HOG+SVM/DPM 就能理解深度学习的动机 |
| 🖼️ **图像拼接 / 全景** | SIFT/SURF/ORB → RANSAC → 单应矩阵 → 图像融合 | ORB 免费够用，SIFT 更稳但慢 |
| 🔬 **做学术研究** | 先看 [系列家族](/global/family) → [演化事件](/global/evolutions) | 挑一个分支深入源码 |

## 常见问答

**Q：传统 CV 是不是已经被深度学习淘汰了？学它还有用吗？**
A：没淘汰。三个理由：①**边缘部署**——没有 GPU 的单片机/ARM 场景，传统 CV 仍是唯一选择；②**可解释性**——工业出问题能定位到具体参数，深度学习黑盒做不到；③**预处理**——深度学习也常用传统算法做前处理（去噪、对齐、裁剪）。

**Q：数学不好能学吗？**
A：能。本站砍掉 90% 公式，用生活化比喻讲。你只要知道「梯度就是像素变化的快慢」「高斯模糊就是加权平均」就能入门。公式放在专门的「概念页」，想看再看。

**Q：要不要从《数字图像处理》(Gonzalez) 开始读？**
A：不推荐上来啃大部头。建议先用本站把 10 个核心算法跑通（OpenCV 调通也就一下午），再回头翻书当字典查。

**Q：Canny/SIFT/HOG 这些要自己实现一遍吗？**
A：**必须。** OpenCV 一行 `cv2.Canny()` 会让你以为自己会了，但只有用 Numpy 写过一遍 NMS、写过双阈值滞后追踪，你才真懂。本站源码页会带你从零写。

**Q：学完传统 CV 怎么转深度学习？**
A：本站 [传承脉络](/legacy/) 页专门讲这件事——YOLO 继承了什么（图像金字塔→FPN、NMS→NMS）、改造了什么（手工特征→CNN、滑窗→网格回归）、抛弃了什么（SIFT 描述子、DPM 部件）。

**Q：OpenCV 版本选哪个？**
A：推荐 **OpenCV 4.x**（Python `pip install opencv-python` 即可）。所有算子页都给了对应的 `cv2.xxx()` 调用。
