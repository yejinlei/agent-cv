# 第 7 页 · 调参口诀

## 一句话调参口诀

```
MOSSE 快但脆；窗要够大、学习率要小、丢了要重检。
```

## 参数速查表

| 参数 | 含义 | 推荐值 | 调大效果 | 调小效果 |
|------|------|--------|----------|----------|
| learning_rate | 学习率 | **0.125** | 跟得紧但易漂 | 更稳但慢适应 |
| sigma | 响应 σ | **2.0** | 响应更集中 | 响应更平坦 |
| psr_threshold | 丢失阈值 | **7.0** | 更易判丢失 | 更宽容 |

## 实战技巧

### 适合场景

目标大小基本不变、光照平稳、追求高帧率的场合。

### 不适合场景

目标剧烈尺度变化、长时间遮挡、需要极高精度的场合——换 CSRT。

### 选型梯度

速度优先 MOSSE > KCF > CSRT；精度优先 CSRT > KCF > MOSSE。

## 性能参考

| 条件 | 耗时 | 说明 |
|------|------|------|
| 320×240 目标窗 | ≈600 FPS | 论文报道，纯 CPU |
| OpenCV TrackerMOSSE | ≈100 FPS | 含全流程开销 |
| 对比 KCF | ≈60 FPS | KCF 慢些但更稳 |

## 选型建议

**适合用**：高速单目标跟踪、无人机视觉跟随、体育转播自动追球、实时 AR 追踪

**不适合用**：不具备尺度自适应、快速运动/遮挡易丢失、精度不如 KCF/CSRT

::: tip 一句话
用傅里叶变换把「找目标」变成「一次乘除」，600 FPS 的开山鼻祖
:::
