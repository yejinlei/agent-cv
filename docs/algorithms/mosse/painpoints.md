# 第 6 页 · 踩坑清单

## 新手最常掉的坑

### 坑 1：跟踪丢失不找回

::: danger 现象
MOSSE 无重检测，目标一旦出窗就永久丢失。
:::

::: tip 解决
接一个 SIFT/模板匹配的全局重检测做找回。
:::

### 坑 2：搜索窗太小

::: danger 现象
目标快速运动一下跳出搜索窗。
:::

::: tip 解决
把搜索窗放到目标尺寸的 1.5~2 倍。
:::

### 坑 3：学习率过高

::: danger 现象
滤波器更新太激进，跟到背景上就漂移。
:::

::: tip 解决
学习率降到 0.02~0.05，或按响应质量自适应。
:::

### 坑 4：用错 API 命名空间

::: danger 现象
cv2.TrackerMOSSE_create 在 4.x 报错。
:::

::: tip 解决
改用 cv2.legacy.TrackerMOSSE_create()。
:::

## 通用调试四步法

1. **可视化中间结果**——不要只盯最终输出，把每一步的中间图都存下来看
2. **先小图后大图**——拿 200×200 的简单图跑通，再上真实场景大图
3. **先默认值后调参**——有 baseline 再改，一次只改一个参数
4. **对齐参考实现**——用 OpenCV 官方 tutorial 的结果做基准，差异大就查原因

## 自查清单

- [ ] 数据类型对不对？（uint8 vs float32 差别巨大）
- [ ] 通道顺序对不对？（BGR vs RGB、灰度 vs 彩色）
- [ ] 图像是否归一化？（0–255 vs 0–1）
- [ ] 边界是否处理？（图像边缘的卷积/插值）
- [ ] 参数单位对不对？（像素 vs 比例、毫秒 vs 秒）
