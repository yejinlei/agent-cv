## 1. 当时的问题

2010 年前的主流跟踪器（如光流、粒子滤波、mean-shift）要么慢、要么对光照形变敏感，难以做到实时高帧率。

## 2. 核心思想

把「定位目标」看成「找一个滤波器，使它对目标图像的响应最大」。训练时用目标区域的多个变形样本，令期望响应是以目标为中心的二维高斯。借助傅里叶变换，卷积变成逐点乘除，训练与推理都极快。

```mermaid
flowchart LR
  A["目标区域样本"] --> B["期望高斯响应"]
  B --> C["FFT域解最小二乘"]
  C --> D["滤波器H"]
  D --> E["新帧相关->峰值定位"]
```

## 3. 关键贡献

- 提出**最小输出平方误差**准则在线训练相关滤波器
- 首次将**FFT 加速的相关滤波**用于跟踪，达 600+ FPS
- 引入 PSR（峰值旁瓣比）判断跟踪是否丢失
- 开创相关滤波跟踪这一谱系

## 4. 核心公式（看懂思路即可）

滤波器 H* = Σ G_i ⊙ F_i* / ( Σ F_i ⊙ F_i* + ε )，其中 F 为输入样本的 FFT、G 为期望响应的 FFT，⊙ 为逐元素乘。下帧响应 y = IFFT( H ⊙ F )。

## 5. 实验结果

在 OTB 等基准上，MOSSE 以远超同期的速度取得当时领先的精度，成为相关滤波跟踪的开山之作。

## 6. 局限与争议

无尺度自适应；无丢失恢复机制；搜索窗固定，快速运动易丢；对旋转敏感。

## 7. 历史影响

直接催生 CSK、KCF、CN、SRDCF、CSRT 等整条相关滤波跟踪谱系，成为传统跟踪领域影响最深的一篇论文之一。

## 8. 一句话总结

> 把跟踪变成一次 FFT 乘除，从此实时跟踪有了「又快又稳」的可能。
