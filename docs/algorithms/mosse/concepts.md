## 先用生活直觉理解

你在找一枚硬币，手里拿着一张「硬币模板」。MOSSE 说：别一格格挪着比，我把它变到频率世界，用一次乘除就知道哪里最像。于是每秒能扫 600 次。它是 KCF、CSRT 这一整族跟踪算法的祖师爷。

**典型应用**：高速单目标跟踪、无人机视觉跟随、体育转播自动追球、实时 AR 追踪

## 概念逐个拆解

### 概念 1：相关运算与响应峰值

把模板在图上滑动做相关，哪里响应最大，哪里就是目标。响应图是一张「相似度地形图」。

```mermaid
flowchart LR
  A["模板"] --> B["与搜索区相关"] --> C["响应图"] --> D["峰值=目标位置"]
```

### 概念 2：为什么用 FFT

相关/卷积在空域是滑窗，在频域是逐点乘。「变换—相乘—反变换」比滑窗快几个数量级。

### 概念 3：期望响应是高斯的

训练时我们希望输出是一张中心为亮斑的高斯图——亮斑中心即目标。滤波器据此求解。

### 概念 4：在线自适应与学习率

每帧用新结果微调滤波器，学习率决定「更新多快」，太快会漂移、太慢跟不上变化。

## 和其他算法的关系

| 关系 | 算法 | 说明 |
|------|------|------|
| 前置依赖 | 灰度化 + 对数/归一化预处理（压光照） | 通常先做这些再做本算法 |
| 同类对比 | KCF、CSRT、CamShift | 解决同类问题，各有取舍 |
| 下游常用 | 尺度估计模块、丢失重检测 | 本算法结果常交给它们处理 |

::: tip 记忆锚点
记住「MOSSE = 相关滤波 + FFT 加速 + 最小输出误差」，速度最快、精度一般。
:::

## 🧓 大白话：MOSSE = "把跟踪当频域相关，快到飞起"

MOSSE（Minimum Output Sum of Squared Error）是所有相关滤波跟踪器的祖宗（2010 年）。它的思路极其朴素：
1. 初始化时，在目标周围取一个跟踪窗口，生成一张**理想响应图**（目标中心是 1 的高斯峰，往外快速衰减到 0）；
2. 在频域里求一个滤波器 H，让 H ⊛ 跟踪窗口 = 理想响应（最小平方误差意义下），即 `H = G ⋆ F / (F ⋆ F)`（频域元素级除法，极快）；
3. 新帧来了，在搜索区做 `response = IFFT(H ⋆ F(F_search))`，找最大值位置就是目标新位置；
4. 更新 H：`H = (1-η)H + ηH_new`。

**速度高达数百 fps**（原始论文作者在 2010 年的 CPU 上就做到 669fps）。代价是精度一般、对尺度/旋转/遮挡都不鲁棒。

## 什么时候用 MOSSE？

- **极高帧率场景**（300fps+ 的嵌入式、无人机高速跟踪）；
- **只需要粗定位**（比如监控里"人还在不在"）；
- **作为跟踪流水线的"快筛"**：MOSSE 快速给候选区，CSRT/KCF 精修。
