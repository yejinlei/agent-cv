## 一句话理解

> 用两视图的匹配点对，解出满足对极约束 x₂ᵀ E x₁ = 0 的本质矩阵，再分解出相机相对旋转与平移方向。

## 为什么需要它？

要从照片重建 3D，第一步永远是「相机在哪、朝哪」。本质矩阵把**两幅图的对应关系**直接翻译成**相机之间的运动**，是一切 SfM、视觉里程计、SLAM 的起点。

## 生活场景

你用手机绕着一栋建筑走一圈拍了几十张照片，想重建出 3D 模型。软件首先要估计每两张照片之间相机移动了多少——靠的就是本质矩阵，再一路串成整条轨迹。
