# 第 6 页 · 踩坑清单

## 新手最常掉的坑

### 坑 1：不归一化坐标

::: danger 现象
直接拿像素坐标求解，得到 F，误以为是 E，位姿全错。
:::

::: tip 解决
先用 K⁻¹ 把点转到归一化相机坐标，或直接调 findEssentialMat 传 K。
:::

### 坑 2：纯旋转场景

::: danger 现象
相机只转不平移，对极约束退化，E 不可解。
:::

::: tip 解决
检测到退化时改用单应矩阵 findHomography 估计旋转。
:::

### 坑 3：平面场景

::: danger 现象
所有对应点共面时求解不稳定。
:::

::: tip 解决
平面场景优先用单应矩阵；若必须用 E，需保证有离面点。
:::

### 坑 4：忘记 4 选 1

::: danger 现象
只分解不筛选，可能选到深度为负的错误位姿。
:::

::: tip 解决
务必用 recoverPose 或三角化验证，取深度全正的那组。
:::

## 通用调试四步法

1. **可视化中间结果**——不要只盯最终输出，把每一步的中间图都存下来看
2. **先小图后大图**——拿 200×200 的简单图跑通，再上真实场景大图
3. **先默认值后调参**——有 baseline 再改，一次只改一个参数
4. **对齐参考实现**——用 OpenCV 官方 tutorial 的结果做基准，差异大就查原因

## 自查清单

- [ ] 数据类型对不对？（uint8 vs float32 差别巨大）
- [ ] 通道顺序对不对？（BGR vs RGB、灰度 vs 彩色）
- [ ] 图像是否归一化？（0–255 vs 0–1）
- [ ] 边界是否处理？（图像边缘的卷积/插值）
- [ ] 参数单位对不对？（像素 vs 比例、毫秒 vs 秒）
