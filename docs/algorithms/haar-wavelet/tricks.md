# 第 7 页 · 调参口诀

## 一句话调参口诀

```
Haar 只有加减、用它做多分辨率；层数别贪多、边界要延拓。
```

## 参数速查表

| 参数 | 含义 | 推荐值 | 调大效果 | 调小效果 |
|------|------|--------|----------|----------|
| level | 分解层数 | **3** | 尺度更粗 | 尺度更细 |
| threshold | 去噪阈值 | **3σ** | 去噪更狠但伤细节 | 去噪弱 |
| wavelet | 小波基 | **haar** | db2 更平滑 | haar 最省算 |

## 实战技巧

### 去噪套路

分解 → 对细节系数软阈值 → 重构，是经典的小波去噪三步曲。

### 和 Viola-Jones 的关系

用积分图快速算矩形灰度差 = Haar 特征的 O(1) 实现，做人脸检测的实时化关键。

### 压缩应用

保留少量大系数、丢弃小系数即可压缩，是 JPEG2000 的核心机制之一。

## 性能参考

| 条件 | 耗时 | 说明 |
|------|------|------|
| 512×512 灰度，3 层 | ≈1 ms | 仅有加减运算 |
| pywt 一层分解 | ≈0.5 ms | PyWavelets 实现 |
| 对比 FFT 同尺寸 | ≈3 ms | 小波明显更快 |

## 选型建议

**适合用**：图像压缩（JPEG2000 概念前身）、多分辨率分析、快速 Haar 特征（Viola-Jones 人脸的基石）、边缘/纹理分析

**不适合用**：小波基粗糙，方向分辨力弱、不如 Daubechies 等平滑小波精细、对噪声敏感（差分量会放大噪声）

::: tip 一句话
用小方波的「平均值与差值」反复分解图像，一眼看出哪里平、哪里有突变
:::

## 🎯 注意

1. OpenCV 没有直接的 Haar 小波函数，要自己用 `resize`（LL）+ 减法（LH/HL/HH）实现；
2. Haar 小波对平移敏感（平移 1 像素，小波系数变化巨大），做匹配时要小心；
3. 小波域去噪 = 对高频子带做软阈值（小系数置 0）再重构，BM3D 之前是最快的去噪之一。
