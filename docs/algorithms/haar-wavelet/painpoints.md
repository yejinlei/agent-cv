# 第 6 页 · 踩坑清单

## 新手最常掉的坑

### 坑 1：层数分解过多

::: danger 现象
 decomposed 到只剩几像素，最粗尺度没有意义。
:::

::: tip 解决
层数控制在 2~5，保证最粗图仍有足够分辨率。
:::

### 坑 2：边界出现伪影

::: danger 现象
滤波在图像边界处理不当产生条纹。
:::

::: tip 解决
指定 mode='symmetric' 或 'periodization'。
:::

### 坑 3：彩色图三通道直接分解

::: danger 现象
色度通道分解意义小且易偏色。
:::

::: tip 解决
转 YCbCr 只分解 Y，或转 Lab 只分解 L。
:::

### 坑 4：阈值一刀切

::: danger 现象
把细节系数全清零，边缘一起没了。
:::

::: tip 解决
用软阈值 + 分尺度自适应阈值（Donoho 方法）。
:::

## 通用调试四步法

1. **可视化中间结果**——不要只盯最终输出，把每一步的中间图都存下来看
2. **先小图后大图**——拿 200×200 的简单图跑通，再上真实场景大图
3. **先默认值后调参**——有 baseline 再改，一次只改一个参数
4. **对齐参考实现**——用 OpenCV 官方 tutorial 的结果做基准，差异大就查原因

## 自查清单

- [ ] 数据类型对不对？（uint8 vs float32 差别巨大）
- [ ] 通道顺序对不对？（BGR vs RGB、灰度 vs 彩色）
- [ ] 图像是否归一化？（0–255 vs 0–1）
- [ ] 边界是否处理？（图像边缘的卷积/插值）
- [ ] 参数单位对不对？（像素 vs 比例、毫秒 vs 秒）
