## 1. 当时的问题

20 世纪初，如何用更局部化的基函数表示信号（相比傅里叶的全局正弦波）是待解问题；傅里叶基在时/空域没有位置信息。

## 2. 核心思想

用最简单的小方波作为基：在一半区间取 +1、另一半取 −1，配合尺度伸缩与位置平移，张成一组正交基。任何信号都能用这些「小方波」的加权和表示，且每个小方波有明确的位置。

```mermaid
flowchart LR
  A["信号"] --> B["与各尺度小方波内积"]
  B --> C["小波系数"]
  C --> D["系数大处=突变/边缘"]
```

## 3. 关键贡献

- 提出第一个**正交小波基**，开创小波分析
- 揭示「尺度 + 位置」双重局部的表示思想
- 为多分辨率分析、Mallat 快速算法奠基
- 成为离散小波变换最简单的实例

## 4. 核心公式（看懂思路即可）

Haar 尺度函数 φ 与 Haar 小波 ψ：
φ(x) = 1 (0≤x<1)，否则 0
ψ(x) = 1 (0≤x<0.5)，−1 (0.5≤x<1)，否则 0
分解即信号与 φ、ψ 的伸缩平移做内积。

## 5. 实验结果

在图像上，一层 Haar 分解把图分成左上低频（趋势）+ 三个方向高频（水平/垂直/对角边缘）；多级分解形成小波金字塔，广泛用于压缩与去噪。

## 6. 局限与争议

小波基不连续，方向选择性弱；图像平滑区域的表现不如 Daubechies/双正交小波；差分量对噪声敏感。

## 7. 历史影响

奠定小波多分辨率分析理论（Mallat 1989 给出快速算法）；直接启发 Viola-Jones 用「矩形区域灰度差」构建 Haar 特征实现实时人脸检测；JPEG2000 采用的小波（CDF 9/7）亦属此家族。

## 8. 一句话总结

> 最朴素的小方波，却开创了「既看频率又看位置」的多分辨率分析。
