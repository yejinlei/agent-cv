# 第 7 页 · 调参口诀

## 一句话调参口诀

```
k 管大小、min_size 管碎块、sigma 先降噪；要区域多就调小 k。
```

## 参数速查表

| 参数 | 含义 | 推荐值 | 调大效果 | 调小效果 |
|------|------|--------|----------|----------|
| k | 尺度参数 | **300** | 区域更大更少 | 区域更小更多 |
| sigma | 平滑 σ | **0.8** | 边界更平滑 | 噪声残留 |
| min_size | 最小区域 | **50** | 碎块更少 | 小目标被吞并 |

## 实战技巧

### 生成候选框

分割后把相邻且颜色相近的区域反复合并成「候选区域」，就是 selective search 的思路，可直接喂给检测器。

### 和 SLIC 对比

要颜色均匀的规则块用 SLIC；要贴合颜色边界的块用 Felzenszwalb。

### 做图像简化

把每个区域填入均值颜色，得到类似油画的简化效果，可用于艺术滤镜。

## 性能参考

| 条件 | 耗时 | 说明 |
|------|------|------|
| 640×480 灰度 | ≈120 ms | Python 实现边排序偏慢 |
| 640×480（C++ 版） | ≈15 ms | 论文报道近线性 |
| 1920×1080（C++ 版） | ≈80 ms | 与像素数近线性 |

## 选型建议

**适合用**：超像素分割、区域建议（R-CNN 的 selectivesearch 借鉴其思想）、图像简化、医学组织分区

**不适合用**：参数 k 控制区域大小，需调、不追求边界精准、对纹理复杂区域容易碎

::: tip 一句话
把图像当成一张图，相邻像素连边，边太「弱」就断开——相邻区域合并成一个块
:::
