## 完整算法流程

Farnebäck 稠密光流算法可以分解为以下关键步骤：

```mermaid
flowchart TB
  A["1. 金字塔构建<br/>构建 n 层高斯金字塔，pyr_scale=0.5（每层缩小一半）"] -->   B["2. 多项式展开<br/>在每层每个像素邻域拟合二次多项式"] -->   C["3. 粗层估计<br/>在最粗层估计初始光流（假设为 0）"] -->   D["4. 上采样 warp<br/>光流上采样到下一层，对 I2 做 warp 补偿"] -->   E["5. 逐层精修<br/>每一层在 warp 后重新估计位移增量，累加到光流"] -->   F["6. 最终输出<br/>到最细层后输出每像素 (u,v)"]
```

## 步骤详解

### 步骤 1：金字塔构建

构建 n 层高斯金字塔，pyr_scale=0.5（每层缩小一半）

### 步骤 2：多项式展开

在每层每个像素邻域拟合二次多项式

### 步骤 3：粗层估计

在最粗层估计初始光流（假设为 0）

### 步骤 4：上采样 warp

光流上采样到下一层，对 I2 做 warp 补偿

### 步骤 5：逐层精修

每一层在 warp 后重新估计位移增量，累加到光流

### 步骤 6：最终输出

到最细层后输出每像素 (u,v)
