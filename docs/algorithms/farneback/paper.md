## 论文背后的故事

Gunnar Farnebäck 是瑞典林雪平大学的教授，他在 2000–2003 年做了一系列关于「基于多项式展开的运动估计」的研究。核心想法很巧妙：不要直接比较两个像素块（像块匹配那样），而是在每个邻域上用二次多项式（二次曲面）拟合亮度，然后根据两帧多项式系数的差解析地解出局部平移。这种方法天然支持多尺度金字塔处理大运动，而且因为多项式展开可以预计算，比 H-S 的变分迭代快很多。OpenCV 在 2006 年左右加入了 calcOpticalFlowFarneback，长期是 CPU 稠密光流的默认选择。

## 核心贡献

Farnebäck 稠密光流 的主要贡献包括：

1. **提出了全新的视角**：用二次多项式拟合邻域，根据多项式系数变化估计稠密光流，CPU 上的经典稠密选择
2. **设计了可落地的算法流程**：兼顾精度与效率
3. **给出了开源实现**：在 OpenCV 等库中成为标准
4. **启发了后续工作**：成为该方向的重要基准
