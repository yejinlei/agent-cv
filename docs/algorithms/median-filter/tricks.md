# 第 7 页 · 调参口诀

## 一句话调参口诀

```
黑白点用中值、3×3 起步、超过 5 就伤线条；高斯噪声请换高斯滤波。
```

## 参数速查表

| 参数 | 含义 | 推荐值 | 调大效果 | 调小效果 |
|------|------|--------|----------|----------|
| ksize | 邻域窗口 | **3** | 更狠去噪但伤细节 | 更保细节但去噪弱 |
| ksize（上限） | 最大窗口 | **5** | 细线消失 | 残留噪声 |

## 实战技巧

### 清二值图

先 medianBlur 3 再去形态学开运算，能把二值图里的孤立小白点清得干干净净。

### 和形态学组合

中值去点、形态学去毛刺，是工业缺陷检测的经典双人组。

### 扫描件去噪

扫描文档用 medianBlur(3) 效果最好，字迹几乎无损。

## 性能参考

| 条件 | 耗时 | 说明 |
|------|------|------|
| 640×480 灰度，ksize=3 | ≈3 ms | 排序实现，未做直方图优化 |
| 640×480 灰度，ksize=5 | ≈8 ms | 窗口变大，耗时上升 |
| 1920×1080 灰度，ksize=5 | ≈40 ms | 高分辨率下建议先降采样 |

## 选型建议

**适合用**：椒盐噪声去除、扫描文档去噪、老照片修复、二值图去小白点

**不适合用**：对高斯噪声效果一般、核大了会抹掉细线条、速度随核平方增长

::: tip 一句话
邻居投票取中位数——椒盐噪声的克星
:::
