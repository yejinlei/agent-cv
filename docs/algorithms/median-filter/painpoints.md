# 第 6 页 · 踩坑清单

## 新手最常掉的坑

### 坑 1：ksize 传偶数或 1

::: danger 现象
OpenCV 要求 ksize 为大于 1 的奇数，传 4 或 1 会直接报错。
:::

::: tip 解决
椒盐去噪从 3 起步；确实要更大就用 5。
:::

### 坑 2：把细线当噪声删掉

::: danger 现象
笔画宽 2 像素而核是 5×5，细线会被整个吃掉。
:::

::: tip 解决
核不超过最细目标宽度的一半；或减少到 3。
:::

### 坑 3：指望它去高斯噪声

::: danger 现象
中值对连续噪声无优势，甚至不如高斯。
:::

::: tip 解决
高斯噪声用 GaussianBlur，脉冲噪声才用 medianBlur。
:::

### 坑 4：彩色图直接三通道中值

::: danger 现象
某些实现按通道独立取中值可能产生色偏。
:::

::: tip 解决
先转 HSV/Lab 只对亮度通道滤波，或改用双边滤波。
:::

## 通用调试四步法

1. **可视化中间结果**——不要只盯最终输出，把每一步的中间图都存下来看
2. **先小图后大图**——拿 200×200 的简单图跑通，再上真实场景大图
3. **先默认值后调参**——有 baseline 再改，一次只改一个参数
4. **对齐参考实现**——用 OpenCV 官方 tutorial 的结果做基准，差异大就查原因

## 自查清单

- [ ] 数据类型对不对？（uint8 vs float32 差别巨大）
- [ ] 通道顺序对不对？（BGR vs RGB、灰度 vs 彩色）
- [ ] 图像是否归一化？（0–255 vs 0–1）
- [ ] 边界是否处理？（图像边缘的卷积/插值）
- [ ] 参数单位对不对？（像素 vs 比例、毫秒 vs 秒）
