# 第 6 页 · 踩坑清单

## 新手最常掉的坑

### 坑 1：鬼影甩不掉

::: danger 现象
初始背景里有车/人，离开后留下鬼影。
:::

::: tip 解决
对持续存在的前景做「二次判定」，或运行若干帧后再作为初始背景。
:::

### 坑 2：缓慢运动被吸收

::: danger 现象
走得很慢的人被样本集接纳为背景。
:::

::: tip 解决
减小 φ 加快更新会加剧此问题；应增大样本集或降低更新率。
:::

### 坑 3：以为 OpenCV 有 ViBe

::: danger 现象
cv2 里找不到 createBackgroundSubtractorViBe。
:::

::: tip 解决
自实现（如上）或用 MOG2 近似，别浪费时间搜索。
:::

### 坑 4：光照突变误检

::: danger 现象
开灯/关灯瞬间满屏前景。
:::

::: tip 解决
检测前景占比异常时重置样本集。
:::

## 通用调试四步法

1. **可视化中间结果**——不要只盯最终输出，把每一步的中间图都存下来看
2. **先小图后大图**——拿 200×200 的简单图跑通，再上真实场景大图
3. **先默认值后调参**——有 baseline 再改，一次只改一个参数
4. **对齐参考实现**——用 OpenCV 官方 tutorial 的结果做基准，差异大就查原因

## 自查清单

- [ ] 数据类型对不对？（uint8 vs float32 差别巨大）
- [ ] 通道顺序对不对？（BGR vs RGB、灰度 vs 彩色）
- [ ] 图像是否归一化？（0–255 vs 0–1）
- [ ] 边界是否处理？（图像边缘的卷积/插值）
- [ ] 参数单位对不对？（像素 vs 比例、毫秒 vs 秒）
