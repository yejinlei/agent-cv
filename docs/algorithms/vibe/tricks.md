# 第 7 页 · 调参口诀

## 一句话调参口诀

```
ViBe 快在极简；首帧别含运动物体，否则出鬼影。
```

## 参数速查表

| 参数 | 含义 | 推荐值 | 调大效果 | 调小效果 |
|------|------|--------|----------|----------|
| N | 样本集大小 | **20** | 更稳但更慢 | 更快但易误检 |
| R | 匹配半径 | **20** | 更宽容、漏检增 | 更敏感、噪声增 |
| phi | 更新概率倒数 | **16** | 更新更慢、更稳 | 更新更快、易吸收前景 |

## 实战技巧

### 多路视频

ViBe 是少数能在单 CPU 核上跑多路 1080p 的背景减除算法。

### 和形态学搭配

ViBe 输出噪点略多，务必接一步开运算 + 连通域过滤。

### 和 KNN 分工

追求稳定用 KNN，追求速度与低内存用 ViBe。

## 性能参考

| 条件 | 耗时 | 说明 |
|------|------|------|
| 640×480 灰度 | ≈1.5 ms/帧 | 极快，常数小 |
| 1920×1080 灰度 | ≈8 ms/帧 | 单核可跑多路 |
| 对比 MOG2 1080p | ≈30 ms/帧 | ViBe 快约 4 倍 |

## 选型建议

**适合用**：嵌入式/低功耗监控、多路视频实时检测、无人机图传前端、FPGA/SoC 视觉

**不适合用**：有「鬼影」（初始背景含运动物体时残留）、对缓慢运动物体可能吸收为背景、OpenCV 无内置（需自己实现或用第三方）

::: tip 一句话
用第一帧就给每个像素塞满样本，再随机更新——极简却极快的背景减除
:::
