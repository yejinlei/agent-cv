# 调参技巧：区域生长分割

## 五字口诀

****种子稳、均值跟、堆排序、遇边停****

## 调参顺序（按这个顺序调，少走弯路）

1. **高斯平滑**（σ=1.5）预处理
2. 种子放在区域内部，每种颜色一个种子 + 一个背景种子
3. LAB 空间 + 颜色欧氏距离（彩色）
4. 8 邻域 heap 生长
5. 结果做闭运算合小孔

## 与其他算法的搭配组合

- **自动种子 + 区域生长**：先用 Otsu/距离变换找硬前景/背景当种子，再 SRG
- **Watershed + SRG 混合**：watershed 容易过分割，SRG 可做区域合并
- **SRG + GrabCut**：SRG 粗分，GrabCut 精修边界
- **SRG + 医学影像**：ITK 里的 ConfidenceConnected 是临床常用工具

## 调优 Checklist

- [ ] 图像已做必要的预处理（高斯平滑 + （彩色时）转 LAB）
- [ ] 核心参数已按场景粗调到合理区间
- [ ] 输出结果做了必要的后处理（小区域合并 + 形态学闭运算）
- [ ] 速度/精度做了 benchmark

## 🎯 使用口诀

> **种子选中间，阈值先小后加；先平滑再生长，不然噪点满图爬。**

1. **先高斯/双边平滑**：噪点会让种子生长出很多毛刺小洞；
2. **8 邻域比 4 邻域生长更自然**：4 邻域只能上下左右，边界呈锯齿；
3. **阈值从低往高调**：调小了长不满，调大了漏出去；
4. **加"同质性准则"**：不仅和区域均值比，还要和区域标准差比，防止在渐变图上一路长出去；
5. **多颗种子并行**：复杂前景点 3~5 颗种子，比一颗种子从头长靠谱得多。
