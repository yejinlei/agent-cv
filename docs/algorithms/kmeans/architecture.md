## 完整算法流程

K-Means 颜色聚类算法可以分解为以下关键步骤：

```mermaid
flowchart TB
  A["1. 特征准备<br/>像素 reshape 成 (N, 3) 浮点；可选：加 (x,y) 变成 5 维，归一化"] -->   B["2. 初始化中心<br/>用 kmeans++ 选 K 个初始中心"] -->   C["3. 分配<br/>每个像素归到最近的中心（按欧氏距离）"] -->   D["4. 更新中心<br/>每个类重新算均值作为新中心"] -->   E["5. 收敛判断<br/>中心移动 < epsilon 或达到最大迭代次数"] -->   F["6. 重建图像<br/>每个像素用其所在类的中心色替换，reshape 回图像形状"]
```

## 步骤详解

### 步骤 1：特征准备

像素 reshape 成 (N, 3) 浮点；可选：加 (x,y) 变成 5 维，归一化

### 步骤 2：初始化中心

用 kmeans++ 选 K 个初始中心

### 步骤 3：分配

每个像素归到最近的中心（按欧氏距离）

### 步骤 4：更新中心

每个类重新算均值作为新中心

### 步骤 5：收敛判断

中心移动 < epsilon 或达到最大迭代次数

### 步骤 6：重建图像

每个像素用其所在类的中心色替换，reshape 回图像形状
