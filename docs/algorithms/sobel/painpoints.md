# Sobel 实战与踩坑

> Sobel 只有几个参数，但踩坑率极高——因为坑大多在**数值类型**和**方向语义**上，代码不报错，结果悄悄错。

## 坑 1：ddepth 用 CV_8U，负梯度被截断 ⭐⭐⭐⭐⭐

```python
# ❌ 错误：负值全部变 0，只剩下「一半」的边缘
gx_wrong = cv2.Sobel(img, cv2.CV_8U, 1, 0)

# ✅ 正确：用有符号类型接住，再翻正
gx = cv2.Sobel(img, cv2.CV_16S, 1, 0)
abs_gx = cv2.convertScaleAbs(gx)
```

**为什么错**：梯度有正有负。左暗右亮的边 → $G_x>0$；左亮右暗的边 → $G_x<0$。`CV_8U` 只存 0-255，所有负值被截成 0，于是「左亮右暗」那一半边缘整条消失。

**症状**：边缘图看起来「只有一半轮廓」，像是被撕掉了一边。

**本体实体**：`pain-sobel-ddepth`

## 坑 2：忘了取绝对值 ⭐⭐⭐⭐⭐

```python
# ❌ 直接看 gx：负值区域显示为黑（其实是强边）
cv2.imshow('gx', gx)          # gx 是 CV_16S，显示时负值被当 0

# ✅ 一定要 convertScaleAbs
abs_gx = cv2.convertScaleAbs(gx)
```

**为什么错**：`imshow` 对 `CV_16S` 的负值处理不符合视觉直觉，负梯度会显示成黑，和「没有边」混在一起。`convertScaleAbs` = 取绝对值 + 缩放 + 转 uint8，一步三用。

## 坑 3：dx / dy 方向搞反 ⭐⭐⭐⭐

```python
# 想要「竖直的边缘」（像门框），应该求 x 方向的导数
gx = cv2.Sobel(img, cv2.CV_16S, 1, 0)   # ✅ dx=1 找竖直边缘

# 记混了写成
gy = cv2.Sobel(img, cv2.CV_16S, 0, 1)   # 这找的是水平边缘
```

**一句话记法**：**对 x 求导 = 找竖直的边**（因为竖直边在水平方向上有变化）。很多人下意识反着记。

**本体实体**：`pain-sobel-direction`

## 坑 4：彩色图直接丢进 Sobel ⭐⭐⭐

```python
# ❌ 三通道图会分别对 B/G/R 求导，得到三张边缘图，很难合并
g = cv2.Sobel(color_img, cv2.CV_16S, 1, 0)

# ✅ 先转灰度
gray = cv2.cvtColor(color_img, cv2.COLOR_BGR2GRAY)
g = cv2.Sobel(gray, cv2.CV_16S, 1, 0)
```

**例外**：如果就是要用颜色边缘（如红/绿边界），应转 HSV 后对**亮度通道**或**色相**单独求导，而不是对 BGR 三通道硬求。

## 坑 5：斜边响应偏弱被误判为「没有边」 ⭐⭐⭐⭐

```python
# 圆形/斜向零件：轴向阈值 60 能过，45° 斜边只剩 0.71 倍，过不了
```

**症状**：同一个圆，正上方和正下方的弧线检测到了，45° 方向的弧线「断了」。

**原因**：Sobel 各向异性，斜边响应 ≈ 轴向的 $1/\sqrt2$。

**三种修法**：

```python
# 修法 1：换 Scharr
gx = cv2.Scharr(img, cv2.CV_16S, 1, 0)
# 修法 2：阈值调低一点，容忍斜边衰减
# 修法 3：改用 Canny（对方向不敏感）
edges = cv2.Canny(img, 50, 150)
```

**本体实体**：`concept-anisotropy`、`pain-sobel-anisotropy`

## 坑 6：ksize 用了偶数或过大 ⭐⭐⭐

```python
# ❌ ksize 必须是正奇数
cv2.Sobel(img, cv2.CV_16S, 1, 0, ksize=4)   # 报错

# ⚠️ ksize 太大（如 31）：边缘被抹得很粗、很慢
cv2.Sobel(img, cv2.CV_16S, 1, 0, ksize=31)
```

**规则**：`ksize` 取 $1, 3, 5, 7, \dots$（奇数）。工业上 **99% 用 3**；`1` 用于「不要平滑、只要原始差分」（HOG、Harris）；`5+` 只在极强噪声下用，代价是边缘变粗。

## 坑 7：没有归一化导致不同图不可比 ⭐⭐⭐

```python
# ❌ 直接比较两张图的原始梯度值
# 曝光不同 → 梯度绝对值不同 → 同一个阈值在两张图上表现完全不同

# ✅ 归一化后再比
mag = cv2.normalize(mag, None, 0, 255, cv2.NORM_MINMAX)
```

**为什么**：Sobel 输出的是「亮度差」，与图像整体对比度正相关。两张曝光不同的图，梯度值不可直接比较。要跨图固定阈值，应先做**归一化**或**光照归一化**。

## 坑 8：在边界处出现假响应 ⭐⭐

图像最外一圈像素做卷积时缺少邻居，OpenCV 用 `BORDER_REFLECT_101` 补，会引入轻微的边界伪影。

```python
# 如果关心边界附近的测量：
padded = cv2.copyMakeBorder(img, 1, 1, 1, 1, cv2.BORDER_REPLICATE)
# 或直接裁掉最外一圈再分析
```

## 坑 9：用 Sobel 找「线」而不是「边」 ⭐⭐⭐

```python
# ❌ 细线（1-2 像素宽）用 Sobel 会得到「两条平行的边」
# ✅ 要找线本身 → 用形态学 top-hat 或 Line Segment Detector
```

**概念区分**：Sobel 找的是**边缘**（亮度阶跃），不是**线**（细窄亮度脊）。一根头发在 Sobel 图上会变成「两侧各一条边」，中间反而是 0。

## 坑 10：以为 Sobel 等于 Canny ⭐⭐⭐⭐

```python
# ❌ 用 Sobel 幅值图当最终边缘结果交差
# ✅ 需要「细、净、连」的边缘 → 用 Canny
```

| 需求 | 该用 |
|---|---|
| 要「哪里有变化」（梯度图） | Sobel |
| 要「一条边一根线」 | Canny |
| 要梯度方向做特征 | Sobel（或 Scharr） |
| 要亚像素边缘位置 | Canny + 亚像素细化 |

## 踩坑速查表

| # | 症状 | 原因 | 修法 |
|---|---|---|---|
| 1 | 边缘只剩半边 | `CV_8U` 截断负值 | 用 `CV_16S` |
| 2 | 强边显示为黑 | 忘了取绝对值 | `convertScaleAbs` |
| 3 | 找错方向的边 | dx/dy 写反 | dx=1 找竖边 |
| 4 | 边缘一片混乱 | 彩色图未转灰度 | 先 `cvtColor` |
| 5 | 斜边断开 | 各向异性 | Scharr / 降阈值 / Canny |
| 6 | 报错或边缘太粗 | ksize 非奇数/过大 | 用 3 |
| 7 | 换图就失效 | 未归一化 | `normalize` |
| 8 | 边框假边 | 边界补零 | 裁一圈或用 pad |
| 9 | 线变两条边 | 混淆边与线 | 用形态学/LSD |
| 10 | 结果不如 Canny | 用途搞错 | 明确需求再选 |

## 诊断 Checklist（结果不对时按顺序查）

- [ ] 输入是不是**单通道灰度**？
- [ ] `ddepth` 是不是 **`CV_16S`/`CV_32F`**？
- [ ] 有没有对结果 **`convertScaleAbs`**？
- [ ] `dx`/`dy` 是否与你想要的边缘**方向一致**？
- [ ] 是否需要**归一化**才能与阈值比较？
- [ ] 斜边漏检 → 试 **Scharr** 或**降阈值**？
- [ ] 这块任务真的适合 Sobel 吗，还是该上 **Canny**？
