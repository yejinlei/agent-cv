## 完整算法流程

MSER 最大稳定极值区域算法可以分解为以下关键步骤：

```mermaid
flowchart TB
  A["1. 像素按灰度排序<br/>把所有像素按灰度值从小到大排序（BINSORT，O(n)）"] -->   B["2. 灌水（并查集合并）<br/>从阈值 0 开始逐步提高，每加一级把该灰度像素加入并查集，和相邻的已加入像素合并"] -->   C["3. 记录区域面积<br/>每个连通分量在每个阈值下记录面积"] -->   D["4. 算稳定度 q(i)<br/>对每个连通分量在每个阈值 i 算 q(i)"] -->   E["5. 选局部极小值<br/>q(i) 的局部极小值对应的区域 = MSER（排除过小/过大区域）"] -->   F["6. 后处理<br/>拟合椭圆/重心，和父/子区域去重（避免重复检测嵌套区域）"]
```

## 步骤详解

### 步骤 1：像素按灰度排序

把所有像素按灰度值从小到大排序（BINSORT，O(n)）

### 步骤 2：灌水（并查集合并）

从阈值 0 开始逐步提高，每加一级把该灰度像素加入并查集，和相邻的已加入像素合并

### 步骤 3：记录区域面积

每个连通分量在每个阈值下记录面积

### 步骤 4：算稳定度 q(i)

对每个连通分量在每个阈值 i 算 q(i)

### 步骤 5：选局部极小值

q(i) 的局部极小值对应的区域 = MSER（排除过小/过大区域）

### 步骤 6：后处理

拟合椭圆/重心，和父/子区域去重（避免重复检测嵌套区域）
