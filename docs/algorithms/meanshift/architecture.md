## 完整算法流程

MeanShift 均值漂移算法可以分解为以下关键步骤：

```mermaid
flowchart TB
  A["1. 图像转 Lab<br/>先转 Lab 颜色空间（欧氏距离更符合感知）"] -->   B["2. 构建金字塔<br/>按 maxLevel 构建高斯金字塔"] -->   C["3. 在最粗层漂移<br/>对每个像素：在 (sp,sr) 窗口内求颜色加权均值 → 移动到均值位置，重复直到收敛"] -->   D["4. 上采样<br/>收敛结果上采样到下一层作为初始值"] -->   E["5. 逐层精修<br/>每层再做几次迭代精修"] -->   F["6. 重建<br/>最终每个像素的颜色值被替换为它收敛到的模式颜色，产生分割效果"]
```

## 步骤详解

### 步骤 1：图像转 Lab

先转 Lab 颜色空间（欧氏距离更符合感知）

### 步骤 2：构建金字塔

按 maxLevel 构建高斯金字塔

### 步骤 3：在最粗层漂移

对每个像素：在 (sp,sr) 窗口内求颜色加权均值 → 移动到均值位置，重复直到收敛

### 步骤 4：上采样

收敛结果上采样到下一层作为初始值

### 步骤 5：逐层精修

每层再做几次迭代精修

### 步骤 6：重建

最终每个像素的颜色值被替换为它收敛到的模式颜色，产生分割效果
