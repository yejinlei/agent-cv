# 第 7 页 · 调参口诀

## 一句话调参口诀

```
浮点用 KD 树、二进制用 LSH；checks 从 50 起；最后必做比率测试。
```

## 参数速查表

| 参数 | 含义 | 推荐值 | 调大效果 | 调小效果 |
|------|------|--------|----------|----------|
| trees | KD-Tree 数量 | **5** | 更准但更慢 | 更快但更漏 |
| checks | 搜索节点数 | **50** | 更准更慢 | 更快更漏 |
| ratio | 比率阈值 | **0.75** | 更严、匹配更少更准 | 更宽、匹配更多更糙 |

## 实战技巧

### 和 RANSAC 必配

FLANN 只负责「像」，几何一致性交给 findHomography + RANSAC。

### 大规模检索

特征库上万张图时，FLANN 建一次索引用多次，或换更快的 Faiss/HNSW。

### 点云配准

ICP 的对应点搜索也常用 KD-Tree 加速，原理与此相同。

## 性能参考

| 条件 | 耗时 | 说明 |
|------|------|------|
| 1000×1000 SIFT 匹配 | ≈25 ms | FLANN，checks=50 |
| 暴力匹配同规模 | ≈900 ms | BFMatcher 对照 |
| 5000×5000 匹配 | ≈300 ms | 规模越大 FLANN 优势越明显 |

## 选型建议

**适合用**：大规模特征匹配（SLAM、全景拼接、图像检索）、SIFT/SURF 描述子匹配、点云配准

**不适合用**：近似结果，可能漏掉真正最近邻、参数（trees/checks）需要调、特征点少时反而不如暴力匹配

::: tip 一句话
不追求百分百准确的最近邻，用「近似」换来几十倍的匹配提速
:::
