# 踩坑与痛点：标定时最常踩的 10 个坑

> 标定看起来简单，但"标出来的参数能不能用"和"标没标出来"是两回事。以下是工业界最常遇到的 10 个坑。

## 坑 1：棋盘不平整 —— 系统性误差最大来源

**症状**：重投影误差看起来很小（< 0.2 px），但拿去做测量偏差很大，越往图像边缘偏差越大。

**原因**：张氏标定的核心假设是"所有标定点在同一个平面上"。A4 纸拿在手里会弯、软纸板会翘、木板会受潮变形——哪怕 0.1 mm 的弯曲，放大到工作距离上就是几毫米的测量误差。

**解决方案**：
- 打印后贴在**玻璃/亚克力/铝塑板**上（平整度 < 0.05 mm）
- 工业场景用**陶瓷棋盘**或**金属棋盘**（精度 0.001 mm）
- 绝对不要用手持 A4 纸直接拍

::: danger 真实案例
某工厂用 A4 纸贴在硬纸板上标定，重投影误差 0.15 px（看起来很好），实际测量零件尺寸偏差 3 mm，耽误一周调试。最终换成玻璃背板后误差立刻降到 0.3 mm。
:::

## 坑 2：所有照片都是正对拍 —— 数学退化

**症状**：标定结果里 fx 和 fy 偏差很大，或者标定结果"不稳定"（同样数据跑两次，内参差很多）。

**原因**：如果所有图片都是相机正对棋盘，所有单应 H 都是近似仿射变换，约束不足——数学上等价于"多张正对拍 = 只拍了 1 张"。

**解决方案**：
- 倾斜 20°~30° 拍几张（朝左、朝右、朝上、朝下倾斜）
- 近/中/远各拍几张
- 棋盘出现在图像四角各几张（有利于畸变估计）

**判断方法**：标定后看 `rvecs`，如果所有 rvec 的旋转角度都 < 10°，就是姿态不够多样。

## 坑 3：内角点数 vs 格子数搞反

**症状**：`findChessboardCorners` 总是返回 `ret=False`，或者偶尔返回 True 但角点顺序错乱。

**原因**：参数 `patternSize=(cols, rows)` 是**内角点**数，不是格子数。
- 棋盘上"黑白方格"的数量是 10×7 个 → 内角点是 9×6 个
- 如果你传 (10, 7) 进去，OpenCV 会找 10×7 = 70 个内角点，当然找不到

**记住**：**内角点 = 格子数 - 1**。数角点比数格子更不容易错——数一下"横着有几个交叉点"就是 cols。

## 坑 4：squareSize 填错 —— 外参比例错但内参没错

**症状**：重投影误差很小，K、dist 看起来正常，但用 PnP 求出来的 tvec 尺寸不对（偏小 10 倍或偏大 10 倍）。

**原因**：squareSize 只影响外参（tvec 的尺度）和投影，**不影响内参 K 和畸变**。所以：
- 如果你只用来去畸变，squareSize 错了没关系（K 是对的）
- 如果你要做测量/PnP/三维重建，squareSize 必须精确到毫米

**解决方案**：标定前用游标卡尺量一下实际格子边长（打印可能有缩放），不要假设"我设置的 25mm 就是 25mm"。

## 坑 5：对焦/变焦动了没重标

**症状**：换场景后测量/位姿突然不准。

**原因**：
- **对焦**会改变镜头到传感器的距离（焦距变化），所以每次重新对焦后 fx、fy 会变
- **变焦镜头**（可调焦）改变焦距后必须重新标定
- 改变光圈一般不影响焦距（可以不重标）

**解决方案**：
- 工业场景**固定对焦+螺纹胶锁死**，标定完不要动
- 如果必须变焦，每个焦距档位都做一次标定，做成"内参查找表"
- 使用定焦镜头 + 锁死焦距

## 坑 6：运动模糊 / 曝光不足 —— 角点检测不准

**症状**：某些图角点检测能过但亚像素漂移大，这些图的单图重投影误差明显高。

**原因**：手持拍摄手抖、曝光时间长导致运动模糊，角点位置精度从 0.01 像素退化到 1 像素以上。

**解决方案**：
- 工业场景用三脚架 + 遥控快门/软件触发
- 保证足够光照 + 短曝光（< 10 ms）
- 拍摄时让画面静止（不要在输送带运行时拍）
- 标定前检查图像：放大角点区域，看是否清晰

## 坑 7：棋盘格占满画面但姿态单调

**症状**：15 张图都是棋盘占满整个画面、正对拍摄——看似"认真拍了"，实际和只拍 3 张正对图没区别。

**原因**："棋盘占满画面"和"姿态多样"是两回事。占满画面只能让角点像素精度高，但如果姿态都是同一个方向，约束仍然不足。

**正确做法**（工业推荐）：
- **4~6 张**：棋盘在画面中心，距离不同（近/中/远），正对
- **4 张**：棋盘朝左倾斜 20~30°，在画面左半部分
- **4 张**：棋盘朝右倾斜 20~30°，在画面右半部分
- **2~4 张**：棋盘上下倾斜，在画面上下部分
- 合计 15~20 张

## 坑 8：忽略主点偏离 —— 强制固定在中心

**症状**：视觉测量时图像中心区域准、边缘区域偏差大，且误差呈系统性偏移。

**原因**：很多教程图省事加 `CALIB_FIX_PRINCIPAL_POINT` 强制主点在图像中心。实际上：
- 消费级镜头主点偏差一般在 ±10 像素以内
- 工业镜头/远心镜头偏差可能达几十像素
- 强制固定主点会把主点偏差"转嫁"到畸变参数上

**解决方案**：
- 默认让主点自由估计（不要加 FIX_PRINCIPAL_POINT）
- 只有当样本量很小（< 5 张图）时才考虑固定
- 标定完检查 cx/cy：如果离图像中心超过 50 像素，可能是角点检测或拍摄有问题

## 坑 9：没评估单图误差 —— 一张坏图毁所有

**症状**：整体 RMSE 看起来还行（0.3 px），但某些方向测量偏差大。

**原因**：整体 RMSE 是平均误差，如果 19 张图误差 0.1 px、1 张图误差 1.5 px，平均下来 0.2 px——但那张坏图可能带偏了某个参数。

**解决方案**：用 [source.md](./source) 里的"工业级标定脚本"，逐图计算误差，剔除误差大于中位数 2 倍的图后重新标定。**工业标准流程一定是"标定→剔除→重标"两步走**。

## 坑 10：标定完没验证就上线

**症状**：上线后发现测量不准，但标定 RMSE 看起来没问题。

**原因**：重投影误差是"训练集误差"——它只衡量"模型对这些标定点拟合得好不好"，不代表"对新数据预测得准不准"。

**验证方法（必做）**：
1. **留一法验证**：标定完后，留一张没参与标定的图，用 solvePnP 求位姿，看角点重投影误差
2. **已知距离验证**：放两个已知距离（比如 100.0 mm）的点在工作平面上，测像素→算距离→和真实值比对
3. **跨工作距离验证**：不同距离、不同角度都测一次
4. **去畸变可视化**：undistort 后看画面里的直线（比如墙角、直尺边）是否真的变直了

**工业上标定合格的标准**（不是 RMSE < 0.2 px，而是）：
- 工作区域内已知距离测量误差 < 1/1000（比如 100 mm 误差 < 0.1 mm）
- 去畸变后直线直线度 < 0.5 像素

## 踩坑速查表

| 症状 | 最可能的坑 | 快速排查 |
|---|---|---|
| RMSE < 0.2 但测量不准 | 坑1（棋盘不平整）| 观察棋盘，用手按一下看是否弯曲 |
| 每次标定 K 差异大 | 坑2（姿态单调）| 打印 rvecs 看旋转角度分布 |
| findChessboardCorners 一直 False | 坑3（patternSize 错）| 数内角点，不是格子数 |
| PnP 位姿尺寸不对 | 坑4（squareSize 错）| 卡尺量格子实际边长 |
| 换场景后突然不准 | 坑5（对焦动了）| 检查镜头是否旋转过 |
| 单图误差差异大 | 坑6（模糊）| 放大坏图看是否模糊 |
| 15 张图还不稳定 | 坑7（姿态单调）| 统计倾斜角度分布 |
| 边缘区域偏差大 | 坑8（主点/畸变）| 去掉 FIX 标志重标 |
| RMSE 看起来好但有方向偏差 | 坑9（坏图污染）| 逐图误差柱状图 |
| 上线后实际测量差 | 坑10（没验证）| 已知距离实机验证 |

## 标定失败诊断 checklist

标定失败时按这个顺序排查：

- [ ] 棋盘是否平整地贴在硬质基板上？
- [ ] 内角点参数 (cols, rows) 对吗？（不是格子数）
- [ ] 所有图像都能检测到完整棋盘吗？（角点是否出界、模糊）
- [ ] 图像姿态够多样吗？（有左/右/上/下倾斜，有近/中/远）
- [ ] squareSize 量过吗？
- [ ] 对焦锁死了吗？
- [ ] 光线均匀吗？（无反光、无局部过曝）
- [ ] 逐图误差都差不多吗？（剔除异常图后重标）
- [ ] 标定完用已知距离做过实机验证吗？
