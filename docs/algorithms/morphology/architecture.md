## 完整算法流程

形态学操作算法可以分解为以下关键步骤：

```mermaid
flowchart TB
  A["1. 选结构元素<br/>根据要处理的目标形状选矩形（MORPH_RECT）、椭圆（MORPH_ELLIPSE）或十字（MORPH_CROSS），确定核大小（奇数）"] -->   B["2. 锚点<br/>默认核中心为锚点，也可自定义"] -->   C["3. 边界处理<br/>图像边界外像素填充常数（默认 0 或复制边界）"] -->   D["4. 邻域 min/max<br/>腐蚀取邻域 min；膨胀取邻域 max"] -->   E["5. 组合运算<br/>开=腐+膨；闭=膨+腐；梯度=膨-腐；顶帽=原-开；黑帽=闭-原"] -->   F["6. 迭代次数<br/>可连续多次迭代，效果类似用更大的核，但速度更快"]
```

## 步骤详解

### 步骤 1：选结构元素

根据要处理的目标形状选矩形（MORPH_RECT）、椭圆（MORPH_ELLIPSE）或十字（MORPH_CROSS），确定核大小（奇数）

### 步骤 2：锚点

默认核中心为锚点，也可自定义

### 步骤 3：边界处理

图像边界外像素填充常数（默认 0 或复制边界）

### 步骤 4：邻域 min/max

腐蚀取邻域 min；膨胀取邻域 max

### 步骤 5：组合运算

开=腐+膨；闭=膨+腐；梯度=膨-腐；顶帽=原-开；黑帽=闭-原

### 步骤 6：迭代次数

可连续多次迭代，效果类似用更大的核，但速度更快
