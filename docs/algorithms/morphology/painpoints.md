## 形态学操作 的常见坑

::: danger 坑：核大小选错，要么过度腐蚀要么没效果
**现象**：核 3×3 没效果，换成 11×11 后目标整个被腐蚀没了。

**解决**：从 **3×3** 起步，先看效果；需要更强时加 iterations 而不是直接换大核。
:::

::: danger 坑：开/闭运算顺序搞反
**现象**：想填小黑洞做了开运算，结果小亮点也被消掉；想去掉小亮点做了闭运算，黑洞没填上。

**解决**：口诀：**开=去亮刺（先腐后膨），闭=填黑洞（先膨后腐）**。
:::

::: danger 坑：在灰度图上乱用二值形态学参数
**现象**：以为形态学只能处理二值图。

**解决**：形态学可以直接处理灰度图！腐蚀=局部 min，膨胀=局部 max。常用于亮度峰值提取、暗细节增强。
:::

::: danger 坑：忘了迭代次数参数
**现象**：要做较强腐蚀时手动调大核导致速度慢。

**解决**：用 `iterations=3` 连续做三次 3×3 腐蚀，比一次 9×9 腐蚀更快、效果类似。
:::

::: danger 坑：边界处理导致边缘黑边
**现象**：腐蚀后图像边缘出现一圈白边或黑边。

**解决**：OpenCV 默认 `BORDER_CONSTANT`，可改用 `borderType=cv2.BORDER_REPLICATE`。
:::

## 调试建议

1. **先可视化中间结果**——不要看最终输出，要一步步看每个中间步骤对不对
2. **先用小图、简单图测试**——确认 pipeline 跑通再上真实场景
3. **参数先从默认值开始**——不要一上来就乱调，有 baseline 再改
4. **对比参考实现**——拿 OpenCV tutorial 或官方 sample 对比自己的结果
