## 完整算法流程

SGM 半全局立体匹配算法可以分解为以下关键步骤：

```mermaid
flowchart TB
  A["1. 双目标定+校正<br/>先标定获取内参、外参、畸变，双目校正把左右图对准（极线水平）"] -->   B["2. 代价计算<br/>对每个像素、每个视差级别计算匹配代价（BT/Census）"] -->   C["3. 代价聚合<br/>沿 8/16 方向用 P1/P2 做动态规划路径聚合"] -->   D["4. WTA 选最优<br/>每个像素选聚合代价最小的视差"] -->   E["5. 亚像素细化<br/>对视差抛物线拟合获得亚像素精度（SGBM 内部分 16 份）"] -->   F["6. 左右一致性检查<br/>算左→右和右→左两张视差图，不一致的点打为无效"] -->   G["7. WLS 滤波<br/>用导向滤波/WLS 平滑视差图，保留边缘"] -->   H["8. 视差→深度<br/>Z = f·B / d（用 reprojectImageTo3D 直接出点云）"]
```

## 步骤详解

### 步骤 1：双目标定+校正

先标定获取内参、外参、畸变，双目校正把左右图对准（极线水平）

### 步骤 2：代价计算

对每个像素、每个视差级别计算匹配代价（BT/Census）

### 步骤 3：代价聚合

沿 8/16 方向用 P1/P2 做动态规划路径聚合

### 步骤 4：WTA 选最优

每个像素选聚合代价最小的视差

### 步骤 5：亚像素细化

对视差抛物线拟合获得亚像素精度（SGBM 内部分 16 份）

### 步骤 6：左右一致性检查

算左→右和右→左两张视差图，不一致的点打为无效

### 步骤 7：WLS 滤波

用导向滤波/WLS 平滑视差图，保留边缘

### 步骤 8：视差→深度

Z = f·B / d（用 reprojectImageTo3D 直接出点云）
