## 单应矩阵 的常见坑

::: danger 坑：以为任何情况都能用 H 配准
**现象**：两张图拍的是 3D 场景（非平面），有平移时 warp 后近处歪了。

**解决**：H **只对平面/纯旋转严格成立**。3D 场景有视差时必须用基础矩阵 F 或三维重建。
:::

::: danger 坑：warpPerspective 之后图像被裁
**现象**：直接用原图尺寸 warp，图跑到画面外。

**解决**：计算 H 后的四个新角点，取最小最大坐标决定新画布大小，然后加平移矩阵。
:::

::: danger 坑：findHomography 不用 RANSAC
**现象**：有几个误匹配时 H 完全错。

**解决**：**永远用 cv2.RANSAC**，阈值 3–5 像素。
:::

::: danger 坑：点共线退化
**现象**：4 个点都在一条线上，H 矩阵解不出来。

**解决**：选 4 个点要**四个角、不共线、尽量分散**。
:::

::: danger 坑：齐次坐标 w 被忽略
**现象**：手算 H·p 时忘了除以第三维 w，结果坐标错。

**解决**：OpenCV warpPerspective 内部做了齐次归一化；自己算时记得除以最后一维。
:::

## 调试建议

1. **先可视化中间结果**——不要看最终输出，要一步步看每个中间步骤对不对
2. **先用小图、简单图测试**——确认 pipeline 跑通再上真实场景
3. **参数先从默认值开始**——不要一上来就乱调，有 baseline 再改
4. **对比参考实现**——拿 OpenCV tutorial 或官方 sample 对比自己的结果
