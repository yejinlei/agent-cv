## 完整算法流程

ICP 迭代最近点算法可以分解为以下关键步骤：

```mermaid
flowchart TB
  A["1. 输入两片点云<br/>源 P、目标 Q，以及可选的初始位姿 T0"] -->   B["2. 初始化<br/>用 T0 变换 P（没有就用单位矩阵）"] -->   C["3. KD-Tree 建 Q 索引<br/>加速最近点查询"] -->   D["4. 找最近点<br/>对 P 中每个点，在 Q 中找最近点（可加距离阈值剔除离群点）"] -->   E["5. 去中心+SVD<br/>计算最优 R、t（基于当前对应）"] -->   F["6. 应用变换<br/>把 P 用新的 (R,t) 变换"] -->   G["7. 收敛判断<br/>平均对应距离变化 < ε 或迭代到 max_iter"]
```

## 步骤详解

### 步骤 1：输入两片点云

源 P、目标 Q，以及可选的初始位姿 T0

### 步骤 2：初始化

用 T0 变换 P（没有就用单位矩阵）

### 步骤 3：KD-Tree 建 Q 索引

加速最近点查询

### 步骤 4：找最近点

对 P 中每个点，在 Q 中找最近点（可加距离阈值剔除离群点）

### 步骤 5：去中心+SVD

计算最优 R、t（基于当前对应）

### 步骤 6：应用变换

把 P 用新的 (R,t) 变换

### 步骤 7：收敛判断

平均对应距离变化 < ε 或迭代到 max_iter
