## ICP 迭代最近点 的常见坑

::: danger 坑：初始位姿差太远
**现象**：两片点云重叠率 < 30% 或初始旋转 > 30°，ICP 收敛到错误局部最优。

**解决**：ICP **不是全局注册**！先用 RANSAC+FPFH/SHOT 特征做粗配准，再用 ICP 精配准。
:::

::: danger 坑：没剔除离群点
**现象**：动态物体、噪声点让 R/t 估计偏。

**解决**：做距离阈值过滤（保留 90% 最近点）或用 Tukey/Huber 鲁棒损失。
:::

::: danger 坑：点到点精度不够
**现象**：大场景下点到点 ICP 收敛慢、RMSE 大。

**解决**：用**点到面 ICP**（需要法线），或更先进的 Generalized-ICP。
:::

::: danger 坑：两片点云密度差太大
**现象**：稀疏点云和稠密点云直接 ICP，对应关系错误。

**解决**：先下采样到同一体素尺寸：`o3d.geometry.voxel_down_sample(voxel_size)`。
:::

::: danger 坑：忘记降采样
**现象**：百万点级别直接跑 ICP 要几分钟。

**解决**：先用**体素下采样**到 5–10cm 体素大小（几千点）跑 ICP，收敛后再上原始点云做最后精调。
:::

## 调试建议

1. **先可视化中间结果**——不要看最终输出，要一步步看每个中间步骤对不对
2. **先用小图、简单图测试**——确认 pipeline 跑通再上真实场景
3. **参数先从默认值开始**——不要一上来就乱调，有 baseline 再改
4. **对比参考实现**——拿 OpenCV tutorial 或官方 sample 对比自己的结果
