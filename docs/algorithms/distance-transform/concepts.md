## 1. 距离的定义

| 距离名 | 公式 | 别名 | 直观理解 |
|---|---|---|---|
| L1 | $|dx| + |dy|$ | 城市块/曼哈顿 | 只能横竖走 |
| L2 | $√(dx²+dy²)$ | 欧氏 | 直线距离 |
| L∞ | $max(|dx|,|dy|)$ | 棋盘 | 王棋一步能到 |
| C | 3/4 倒角 | Chamfer | 横竖 3、对角 4 近似 L2 |

## 2. 两次扫描递推的核心思想

如果一个像素 (i,j) 的最近背景点是它自己（它自己就是背景），D=0；否则它的最近距离 = 1 + min{邻居们的最近距离}。但这需要迭代多轮。两次扫描的巧妙在于：

- **第一遍（左上→右下）**：利用「已经扫过」的左上邻居，把左上方向的距离信息传过来
- **第二遍（右下→左上）**：反过来利用右下邻居传右下方向信息

两遍之后信息就传遍整张图了。

## 3. 距离变换 vs 骨架化

距离变换局部最大值连起来就是「骨架」（skeleton / medial axis）：
- **距离局部极大**：比所有 8 邻域都大的点
- 骨架上每个点的距离值 = 它所在位置的「宽度半径」，也就是「这根血管有多粗」

## 4. 标签距离变换（带索引）

DIST_LABEL_PIXEL / DIST_LABEL_CCOMP 选项不仅给距离，还告诉你最近的 0 像素是哪个标签/哪个连通域——这就是**分水岭算法找种子**的核心。

## 🧓 大白话：距离变换 = "每个位置离最近的边界有多远"

对一张二值图（前景白、背景黑），距离变换给**每个白像素**计算"离最近黑像素的距离"，结果是一张灰度图：越亮代表离边界越远（越靠内部），越暗代表越靠近边界。

这是一个**基础工具**，本身不是完整算法，但在很多高级方法里是关键一步：
- **细化/骨架提取**：取距离变换的局部最大值，就是骨架；
- **匹配（Chamfer Matching）**：模板边缘和图像边缘距离越小越匹配；
- **分割后处理**：距离变换峰值 = 各连通块中心（比连通域中心稳）；
- **文字识别**：先距离变换再做归一化，对齐字符笔画粗细。

## 三种距离

| 距离类型 | 精度 | 速度 | 应用 |
| --- | --- | --- | --- |
| **DIST_L1**（曼哈顿）| 低 | ⚡最快 | 粗略骨架 |
| **DIST_L2**（欧氏）| 高 | 较快 | 通用首选 |
| **DIST_C**（棋盘）| 低 | 快 | 形态学预处理 |
