# 论文精读 · RANSAC (1981)

> **Fischler, M. A., & Bolles, R. C. (1981). Random Sample Consensus: A Paradigm for Model Fitting with Applications to Image Analysis and Automated Cartography. *Communications of the ACM*, 24(6), 381–395.**
> DOI: 10.1145/358669.358692　引用量：14000+

## 它诞生在一个什么困境里

1980 年前后，计算机视觉刚开始处理真实图像，研究者普遍的做法是**先提特征、再用最小二乘拟合**。问题出在第二步：

- 图像里的特征提取**永远不完美**——边缘会断、角点会错、匹配会错。这些错误数据在统计上叫**外点（outlier）**。
- **最小二乘有一个致命弱点：它追求误差平方和最小，而平方会放大外点的影响。** 只要有 1 个离谱的外点，拟合出的直线就会被硬生生拽过去。
- 当时的标准补救办法是先做「数据清理」（如残差阈值迭代剔除），但**清理规则本身又依赖一个尚未确定的模型**，陷入鸡生蛋循环。

论文作者 Fischler 和 Bolles 在 SRI International（斯坦福国际研究院）工作，背景是**自动化制图**——从航空照片里自动识别道路、建筑，再画成地图。这类任务的特征噪声极大，传统拟合完全不可用。

## 三大核心贡献

### 贡献一：把数据明确分成内点与外点，且对外点不作任何分布假设

这是最根本的观念转变。此前的拟合方法（最小二乘、M 估计）都隐含假设「误差服从某种分布，只是尾巴厚一点」。RANSAC 说：

> **外点可以服从任何分布，甚至可以是有意破坏的。我不去建模它们，我只要找到那个「内点都同意」的模型。**

论文原话称之为「外点可以是任意分布的、无结构的噪声」。这个放弃对噪声建模的决断，正是它 44 年不过时的原因。

### 贡献二：提出「随机采样 → 假设 → 验证」的范式

RANSAC 把拟合问题拆成两件互不干扰的事：

1. **产生模型假设**：从数据里**随机抽最小样本集**，用它们解出候选模型。样本越小，抽到全内点的概率越高（直线取 2 点、单应矩阵取 4 点）。
2. **验证假设**：让**全部**数据对候选模型投票，距离小于阈值 $t$ 的算内点，内点数就是模型得分。

这个「猜→验」的结构后来被反复借鉴：霍夫变换是「参数空间投票」，RANSAC 是「数据空间随机假设」，深度学习里的 RANSAC 系（如 DSAC、Neural-Guided RANSAC）则是「用网络产生假设」。

### 贡献三：给出可计算的迭代次数公式

「随机采样要试多少次才够？」论文给出了一个能直接算的答案：

$$k = \frac{\log(1-p)}{\log\left(1-w^{s}\right)}$$

其中 $w$ 是内点率、$s$ 是最小样本数、$p$ 是期望的成功概率（通常取 0.99）。**关键洞察**：$w$ 在内点率低时会指数级放大 $k$——内点率 50%、$s=4$ 时约需 35 次，内点率 20% 时则要 1000 次以上。这个公式让 RANSAC 从「碰运气」变成了可工程化的方法。

论文还提出了**自适应版本**：不必事先知道 $w$，而是每轮用**当前最优模型的内点率**重新估计 $k$，内点率高时提前收敛。

## 论文里的原始算法

```
给定：数据点集 P、最小样本数 s、距离阈值 t、目标成功概率 p
1. k = ∞, best_model = None, best_inliers = 0
2. 重复：
   a. 从 P 随机抽 s 个点，拟合出候选模型 M
   b. 统计 P 中到 M 的距离 < t 的点，得到内点集 I
   c. 若 |I| > best_inliers：best_model = M，best_inliers = |I|
   d. 由当前内点率 w = best_inliers / |P| 重算 k = log(1-p) / log(1 - w^s)
   e. 若已迭代次数 ≥ k：跳出
3. 用 best_model 对应的全部内点重新拟合，输出最终模型
```

论文同时给出了**退化情形处理**建议：如果抽到的样本无法确定唯一模型（如两点重合导致直线无定义），直接跳过本轮重抽。

## 论文里的三个经典实验

| 实验 | 任务 | 结果 |
|---|---|---|
| **直线拟合** | 合成数据 + 可控外点率 | 外点率 50% 时依然精确恢复直线；最小二乘在 10% 外点时就已崩溃 |
| **单应矩阵（Homography）** | 同一平面的两视图匹配点，求平面透视变换 | 用 4 点最小样本，成功在含大量错误匹配的点集中恢复 H，直接用于图像拼接 |
| **立体视觉对应点筛选** | 左右视图特征匹配 + 极线约束 | 用 RANSAC 剔除错误匹配，为后续三维重建提供干净的对应点 |

其中单应矩阵实验是**今天所有图像拼接、AR 平面跟踪的祖师爷**——它证明了「用 RANSAC 收尾的匹配」能从脏数据里长出干净几何。

## 三个反直觉但重要的事实

1. **RANSAC 不是「找误差最小的模型」，而是「找支持者最多的模型」**。评分用的是内点**个数**，不是误差平方和——这正是它能免疫外点的原因。
2. **随机采样不是缺点，是特性**。采样带来的随机性让算法能跳出局部最优；最后一步「用全部内点重新拟合」把随机性抹平，输出是确定且唯一的。
3. **RANSAC 的成功率可以量化**。$p$ 是你自己设的，取 0.99 表示「我愿意接受 1% 的失败概率」。这个概率是**可计算、可验证**的，不是玄学。

## 后续影响链

| 年份 | 工作 | 相对 RANSAC 的改进 |
|---|---|---|
| 1984 | LMedS | 用残差中位数替代内点计数，抗外点率更高 |
| 1995 | MSAC | 内点记固定分、外点按误差扣分，评分更平滑 |
| 2000 | MLESAC | 用最大似然框架统一 MSAC 与 LMedS |
| 2003 | LO-RANSAC | 找到候选模型后做局部优化再计票，低内点率下精度大幅提升 |
| 2005 | PROSAC | 按匹配质量（描述子距离）降序采样，特征匹配场景收敛更快 |
| 2013 | USAC | 融合上述优点，成为现代标准实现（OpenCV 部分 API 已采用） |
| 2017+ | DSAC / NG-RANSAC | 用神经网络预测内点概率，指导采样，端到端可学习 |

## 一句话总结

> **RANSAC 的伟大不在于数学有多深，而在于它承认了一个工程现实：现实数据里总有脏东西，与其硬算，不如随机猜、用一致性投票挑出最好的那个。** 44 年后它仍是所有几何估计的最后一道工序。
