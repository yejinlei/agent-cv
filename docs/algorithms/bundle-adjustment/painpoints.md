# 第 6 页 · 踩坑清单

## 新手最常掉的坑

### 坑 1：初值太差直接发散

::: danger 现象
位姿初值错得离谱时，LM 也拉不回来。
:::

::: tip 解决
先用 PnP / 三角化拿到不错的初值，再上 BA。
:::

### 坑 2：不用鲁棒损失

::: danger 现象
少量误匹配就能把全局优化带偏。
:::

::: tip 解决
用 Huber / Cauchy 损失，或先做 RANSAC 清匹配。
:::

### 坑 3：全参数一起优化内参

::: danger 现象
数据不足时内参过拟合，结果发散。
:::

::: tip 解决
数据量小时固定内参，只优化位姿与点。
:::

### 坑 4：自己手写大规模 BA

::: danger 现象
内存爆炸、速度感人。
:::

::: tip 解决
用 Ceres/g2o，它们内置稀疏结构与高效求解。
:::

## 通用调试四步法

1. **可视化中间结果**——不要只盯最终输出，把每一步的中间图都存下来看
2. **先小图后大图**——拿 200×200 的简单图跑通，再上真实场景大图
3. **先默认值后调参**——有 baseline 再改，一次只改一个参数
4. **对齐参考实现**——用 OpenCV 官方 tutorial 的结果做基准，差异大就查原因

## 自查清单

- [ ] 数据类型对不对？（uint8 vs float32 差别巨大）
- [ ] 通道顺序对不对？（BGR vs RGB、灰度 vs 彩色）
- [ ] 图像是否归一化？（0–255 vs 0–1）
- [ ] 边界是否处理？（图像边缘的卷积/插值）
- [ ] 参数单位对不对？（像素 vs 比例、毫秒 vs 秒）
