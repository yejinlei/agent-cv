# 第 7 页 · 调参口诀

## 一句话调参口诀

```
先限半径、再去噪、param2 由小到大扫——票数够才算圆。
```

## 参数速查表

| 参数 | 含义 | 推荐值 | 调大效果 | 调小效果 |
|------|------|--------|----------|----------|
| dp | 累加器精度 | **1.2** | 更快更粗 | 更慢更准 |
| minDist | 圆心最小间距 | **30** | 重叠圆被抑制 | 易出现重复圆 |
| param2 | 圆心阈值 | **30** | 误检减少 | 漏检增加 |
| param1 | Canny 高阈值 | **100** | 边缘减少 | 噪声边缘增加 |

## 实战技巧

### 先粗后精

先用小图快速定位大致圆，再在原图局部做精修，兼顾速度与精度。

### 半径范围二分

不确定半径时，可先跑一个很宽的范围看都检出什么，再收紧。

### 和轮廓法互补

轮廓完整、无遮挡时用 fitEllipse/最小外接圆更快；遮挡严重时才上霍夫。

## 性能参考

| 条件 | 耗时 | 说明 |
|------|------|------|
| 640×480，半径 10~80 | ≈25 ms | dp=1.2，约 36 个半径档 |
| 1920×1080，半径 10~80 | ≈180 ms | 分辨率高，投票基数大 |
| 1920×1080，半径不限 | >2 s | 反面教材：必须限制半径 |

## 选型建议

**适合用**：硬币/零件计数、虹膜定位、仪表盘指针圆盘、交通标志检测、细胞计数

**不适合用**：参数（dp/minDist/两阈值）敏感难调、内存/时间随图像与半径范围增长、同心圆、重叠圆易误检

::: tip 一句话
给每个边缘点投一票，票数最高的圆心就是真圆
:::
