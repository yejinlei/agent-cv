# 第 6 页 · 踩坑清单

## 新手最常掉的坑

### 坑 1：半径范围留空 = 卡死

::: danger 现象
minRadius=maxRadius=0 时 OpenCV 会遍历很大范围，1080p 图可能几秒才返回。
:::

::: tip 解决
务必根据目标实际尺寸填 minRadius/maxRadius。
:::

### 坑 2：param2 调太小

::: danger 现象
圆心阈值过低，噪声点聚成假圆，检出几百个。
:::

::: tip 解决
param2 从 30 起步，逐步加大直到误检消失。
:::

### 坑 3：去噪不充分

::: danger 现象
边缘图里满是噪点边缘，投票被污染。
:::

::: tip 解决
前置 medianBlur(5) 或 GaussianBlur，再进 HoughCircles。
:::

### 坑 4：同心圆只剩一个

::: danger 现象
minDist 把同一圆心附近的其他半径圆抑制掉了。
:::

::: tip 解决
需要检测同心圆时降到 minDist 并缩小半径范围分批检测。
:::

## 通用调试四步法

1. **可视化中间结果**——不要只盯最终输出，把每一步的中间图都存下来看
2. **先小图后大图**——拿 200×200 的简单图跑通，再上真实场景大图
3. **先默认值后调参**——有 baseline 再改，一次只改一个参数
4. **对齐参考实现**——用 OpenCV 官方 tutorial 的结果做基准，差异大就查原因

## 自查清单

- [ ] 数据类型对不对？（uint8 vs float32 差别巨大）
- [ ] 通道顺序对不对？（BGR vs RGB、灰度 vs 彩色）
- [ ] 图像是否归一化？（0–255 vs 0–1）
- [ ] 边界是否处理？（图像边缘的卷积/插值）
- [ ] 参数单位对不对？（像素 vs 比例、毫秒 vs 秒）
