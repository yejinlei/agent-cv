## 1. 当时的问题

1962 年 Paul Hough 提出用参数空间投票检测直线，但难以推广到圆等复杂曲线；直接用三点定圆再验证的计算量又太大。

## 2. 核心思想

把图像中「共圆的一群点」映射到参数空间「同一个 (a,b,r)」，让它们在那里叠加投票。票数高的参数组合就是图像中的真圆。再用边缘梯度方向把搜索范围缩小，避免三维遍历。

```mermaid
flowchart LR
  A["边缘点(x,y)"] --> B["按梯度方向枚举圆心(a,b)"]
  B --> C["参数空间累加"]
  C --> D["找峰值 -> 圆"]
```

## 3. 关键贡献

- 把霍夫变换从直线推广到任意解析曲线
- 引入**梯度方向约束**，把圆的参数搜索从三维降到二维
- 提出累加器阈值决定「多少票算一个圆」

## 4. 核心公式（看懂思路即可）

圆方程 (x−a)² + (y−b)² = r²。边缘点梯度方向指向圆心，故圆心位于 (x − r·cosθ, y − r·sinθ)，θ 为梯度方向——只需遍历 r，a、b 直接算出。

## 5. 实验结果

在手绘与实拍含圆图像上，配合 Canny 边缘，霍夫圆对噪声与部分遮挡表现稳健，检测率显著优于「先分割再拟合」。

## 6. 局限与争议

参数敏感、内存大；同心圆难分离；对椭圆、非圆曲线需另行推广；精度受累加器量化影响。

## 7. 历史影响

成为圆形目标检测的教科书方法，广泛用于硬币/细胞/虹膜/仪表检测；后续又衍生出随机霍夫变换、霍夫椭圆、广义霍夫变换（用于任意形状模板匹配）。

## 8. 一句话总结

> 「众人投票」四个字，撑起了传统 CV 检测几何图形的半壁江山。
