# 第 6 页 · 踩坑清单

## 新手最常掉的坑

### 坑 1：epsilon 设成绝对值

::: danger 现象
epsilon 是长度，与图像分辨率强相关，写死 5 像素在不同分辨率下效果天差地别。
:::

::: tip 解决
始终用「周长的百分比」来算 epsilon。
:::

### 坑 2：正方形被磨圆

::: danger 现象
epsilon 取到周长 5%，方角被当噪声砍掉。
:::

::: tip 解决
降到 1%~2%，或改用 approxPolyDP 后检测顶点数。
:::

### 坑 3：椭圆被离群点拽歪

::: danger 现象
边缘有毛刺或少量远点时，普通 fitEllipse 结果离谱。
:::

::: tip 解决
先平滑轮廓，或用 RANSAC 版椭圆拟合。
:::

### 坑 4：点太少直接报错

::: danger 现象
轮廓面积太小、点数不足 5，fitEllipse 抛异常。
:::

::: tip 解决
先用 contourArea 过滤小轮廓，再判断 len(cnt)>=5。
:::

## 通用调试四步法

1. **可视化中间结果**——不要只盯最终输出，把每一步的中间图都存下来看
2. **先小图后大图**——拿 200×200 的简单图跑通，再上真实场景大图
3. **先默认值后调参**——有 baseline 再改，一次只改一个参数
4. **对齐参考实现**——用 OpenCV 官方 tutorial 的结果做基准，差异大就查原因

## 自查清单

- [ ] 数据类型对不对？（uint8 vs float32 差别巨大）
- [ ] 通道顺序对不对？（BGR vs RGB、灰度 vs 彩色）
- [ ] 图像是否归一化？（0–255 vs 0–1）
- [ ] 边界是否处理？（图像边缘的卷积/插值）
- [ ] 参数单位对不对？（像素 vs 比例、毫秒 vs 秒）
