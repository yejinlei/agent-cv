# 第 6 页 · 踩坑清单

## 新手最常掉的坑

### 坑 1：忘记过滤阴影

::: danger 现象
阴影像素值 127 被当成前景，目标旁边拖一条灰影。
:::

::: tip 解决
用 threshold(fg,200,255) 把非纯白像素滤掉。
:::

### 坑 2：不做形态学后处理

::: danger 现象
掩码里全是胡椒面噪点，无法用于后续分析。
:::

::: tip 解决
开运算去小噪点、膨胀连通目标。
:::

### 坑 3：nSamples 设成 50

::: danger 现象
内存与耗时陡增，效果却提升有限。
:::

::: tip 解决
10~20 足够，过高收益递减。
:::

### 坑 4：光照突变不重学

::: danger 现象
自动曝光突变导致整屏误检。
:::

::: tip 解决
检测到前景占比异常时重置背景模型。
:::

## 通用调试四步法

1. **可视化中间结果**——不要只盯最终输出，把每一步的中间图都存下来看
2. **先小图后大图**——拿 200×200 的简单图跑通，再上真实场景大图
3. **先默认值后调参**——有 baseline 再改，一次只改一个参数
4. **对齐参考实现**——用 OpenCV 官方 tutorial 的结果做基准，差异大就查原因

## 自查清单

- [ ] 数据类型对不对？（uint8 vs float32 差别巨大）
- [ ] 通道顺序对不对？（BGR vs RGB、灰度 vs 彩色）
- [ ] 图像是否归一化？（0–255 vs 0–1）
- [ ] 边界是否处理？（图像边缘的卷积/插值）
- [ ] 参数单位对不对？（像素 vs 比例、毫秒 vs 秒）
