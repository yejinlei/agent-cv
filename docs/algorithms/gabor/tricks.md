# 调参技巧：Gabor 滤波器

## 五字口诀

****波长细、方向八、σ 配 λ、零均归****

## 调参顺序（按这个顺序调，少走弯路）

1. 灰度化 + 直方图均衡/CLAHE
2. **方向 8 个、尺度 5 个**作为默认组
3. ksize = 6σ+1（奇数），sigma=0.56λ
4. 取 abs() 作为响应幅度
5. 每通道 z-score 归一化后再拼特征

## 与其他算法的搭配组合

- **Gabor + SVM**：经典纹理分类 pipeline（Brodatz、KTH-TIPS）
- **Gabor 增强 + 细化 + 特征点**：指纹识别（Hong-Jain 1998）
- **Gabor 幅值图 + LBP**：多特征融合纹理分类
- **多方向 Gabor max**：Canny 的替代方案（多尺度多方向边缘）

## 调优 Checklist

- [ ] 图像已做必要的预处理（灰度化 + CLAHE/归一化增强）
- [ ] 核心参数已按场景粗调到合理区间
- [ ] 输出结果做了必要的后处理（归一化响应，再做分类/检测）
- [ ] 速度/精度做了 benchmark

## 🎯 实战要点

1. **典型配置**：5 个尺度（λ: 3,4,6,8,12）× 8 个方向（0°~180° 每 22.5°）= 40 个核，能覆盖绝大多数纹理；
2. **必须做归一化**：不同核的响应幅值差异大，直接拼起来大响应会压住小响应；
3. **降采样加速**：Gabor 响应是过完备的，可以下采样到 1/4 再拼，速度快 16 倍；
4. **PCA 降维**：40 通道拼起来向量太长，用 PCA 压到 50~100 维再送 SVM；
5. **Gabor 卷积可通过 FFT 加速**（频域乘），大核时比空间卷积快。
