## 核心概念详解

### 概念1：n 点透视问题

已知 n 个 3D 点在世界坐标系的位置，以及它们在图像上的 2D 投影，求相机外参 [R|t]（相机相对于世界坐标系的旋转+平移，共 6DoF）。这就是经典的 PnP（Perspective-n-Point）问题。

### 概念2：3D-2D 对应

核心方程是投影公式：s·p = K[R|t]·P，其中 P 是 3D 点齐次坐标、p 是 2D 像素齐次坐标、K 是内参、[R|t] 是外参。n 对 (P_i, p_i) 给你，求 R 和 t。

### 概念3：P3P 与 EPnP

P3P：3 对点最多 4 个解，需要第 4 点消歧；EPnP（Lepetit 2009）：把 3D 点表示为 4 个虚拟控制点的加权和，复杂度 O(n)，是现代最常用方法；Iterative：基于 Levenberg-Marquardt 迭代最小化重投影误差，精度最高但慢。

### 概念4：RANSAC 抗外点

实际场景匹配往往有误匹配（外点），`solvePnPRansac` 会多次随机采样最小子集求解并选内点最多的模型，鲁棒性强。

## 🧓 大白话：PnP = "已知 3D 点和它们在图上的位置，求相机在哪"

Perspective-n-Point 问题：你在世界坐标系里有 N 个点的 3D 坐标（比如棋盘格角点、人脸关键点、SLAM 地图点），你在照片里看到了它们对应的 2D 像素，并且你**已知相机内参 K**——求相机的外参（旋转 R 和平移 t，也就是"相机在哪、朝哪看"）。

这是**增强现实、无人机着陆、机器人抓取、单目定位**的核心几何问题。

## 六种解法对比

| 方法 | 最少点数 | 特点 |
| --- | --- | --- |
| **P3P** | 3 | 快，但只用 3 点，精度受噪声影响大 |
| **EPnP** | 4 | O(n)，精度高（OpenCV 默认） |
| **ITERATIVE** | 4+ | 用 Levenberg-Marquardt 迭代精修 EPnP 结果 |
| **IPPE** | 4 | 共面点专用，更稳 |
| **DLS** | 3 | 直接最小二乘，精度中 |
| **SOLVEPNP_AP3P**| 4 | 鲁棒版本 |

## 典型配置

- 先用 **SOLVEPNP_EPNP** 拿初值，再用 **SOLVEPNP_ITERATIVE** 精修；
- 必须配 **RANSAC**（`solvePnPRansac`）过滤 outlier，否则一个错点就能毁所有；
- 点要**在 3D 空间分布开**（别都在一个平面上/一条线上），否则解不稳定。
