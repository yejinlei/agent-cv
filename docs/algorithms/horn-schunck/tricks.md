## Horn-Schunck 稠密光流 调参口诀

```
alpha 十左右是默认，越大越平滑小越细；
迭代一百次起步，少了不收敛；
IxIy  Sobel 核除以八，It  是两帧差；
邻域平均用拉普拉斯核，高斯赛德尔迭代；
大运动一定要金字塔，不然结果全是瞎猜；
HS 是教学基准多，工程请用 Farneback 或 DIS。
```

## 参数速查表

| 参数 | 含义 | 推荐值 | 调大效果 | 调小效果 |
|---|---|---|---|---|
| alpha | 平滑强度 | **10** | 平滑 | 保留细节 |
| n_iter | 迭代次数 | **100** | 收敛好 | 快 |
| pyramid levels | 金字塔层数 | **3** | 处理大运动 | 快 |

## 实战技巧

### HSV 色轮可视化

色调=方向，饱和度=255，明度=幅度。这种可视化能一眼看出光流的方向和大小分布。

### 稠密光流 vs 稀疏光流选择

| 任务 | 选谁 |
|---|---|
| 跟踪目标位置 | LK 稀疏光流 |
| 视频稳像 | LK 或 Farneback |
| 动作识别输入 | Farneback 稠密 |
| 变分光流研究 | HS/TV-L1 |
| 实时 VO | 稀疏特征+LK |

## 性能参考

| 条件 | 耗时 | 说明 |
|---|---|---|
| HS n_iter=100 (640×480) | ~3-5 s | 纯 Python，慢 |
| C++ 优化版 | ~100 ms | CPU |
| Farneback (640×480) | ~200 ms | OpenCV C++ |

## 选型建议

**适用场景**：稠密运动场估计、流体运动分析、医学影像序列、变分光流研究基准、视频慢动作插帧（传统方法）

**不适用场景**：迭代慢、大运动不适用(需金字塔)、运动边界过度平滑
