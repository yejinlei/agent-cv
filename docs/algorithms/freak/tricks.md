# 第 7 页 · 调参口诀

## 一句话调参口诀

```
FREAK 只描述不检测；二进制必配汉明距离；采样尺度要对上图像尺度。
```

## 参数速查表

| 参数 | 含义 | 推荐值 | 调大效果 | 调小效果 |
|------|------|--------|----------|----------|
| patternScale | 采样模式尺度 | **22.0** | 视野更大、抗形变 | 更精细但对尺度敏感 |
| orientationNormalized | 方向归一化 | **True** | — | 发现旋转不变性丢失时改 True |
| nOctaves | 金字塔层数 | **4** | 更强的尺度覆盖 | 更快但尺度覆盖弱 |

## 实战技巧

### 和 ORB 搭配

用 ORB 检测器（自带方向与金字塔）出点，再用 FREAK 描述，往往比原生 ORB 描述子更稳。

### 级联匹配提速

先用短描述子粗筛，再对候选做完整汉明距离，能再快一倍。

### 移动端部署

FREAK 计算量小、描述子短，是 TensorFlow Lite 时代之前移动端匹配的首选之一。

## 性能参考

| 条件 | 耗时 | 说明 |
|------|------|------|
| 1000 个特征点，512 位 | ≈8 ms | 单核，含采样与比较 |
| 1000×1000 暴力汉明匹配 | ≈15 ms | 含 crossCheck |
| 移动端 ARM（估） | ≈25 ms | 算力约为桌面 1/3 |

## 选型建议

**适合用**：移动端/嵌入式实时匹配、AR、物体识别，在算力受限设备上替代 SIFT/SURF

**不适合用**：不具备尺度不变性（需配金字塔）、旋转不变性靠估计方向，不如 ORB 稳、对视角变化较敏感

::: tip 一句话
模仿人眼视网膜的采样模式，用 512 位二进制串描述特征点
:::
