# 第 6 页 · 踩坑清单

## 新手最常掉的坑

### 坑 1：直接对原图 compute

::: danger 现象
有人以为 FREAK 能自己找点，其实必须先 detect 出关键点。
:::

::: tip 解决
先用 FastFeatureDetector 或 ORB 检测器拿到 kp。
:::

### 坑 2：patternScale 乱设

::: danger 现象
采样半径与图像尺度不匹配，导致描述子区分度差。
:::

::: tip 解决
图像大时适当放大 patternScale，小图用默认值。
:::

### 坑 3：用欧氏距离匹配

::: danger 现象
二进制描述子算欧氏距离没有任何意义。
:::

::: tip 解决
匹配器必须指定 cv2.NORM_HAMMING。
:::

### 坑 4：忽略尺度金字塔

::: danger 现象
跨尺度场景下不配金字塔，匹配几乎全军覆没。
:::

::: tip 解决
检测阶段就在金字塔上取点（ORB 检测器自带）。
:::

## 通用调试四步法

1. **可视化中间结果**——不要只盯最终输出，把每一步的中间图都存下来看
2. **先小图后大图**——拿 200×200 的简单图跑通，再上真实场景大图
3. **先默认值后调参**——有 baseline 再改，一次只改一个参数
4. **对齐参考实现**——用 OpenCV 官方 tutorial 的结果做基准，差异大就查原因

## 自查清单

- [ ] 数据类型对不对？（uint8 vs float32 差别巨大）
- [ ] 通道顺序对不对？（BGR vs RGB、灰度 vs 彩色）
- [ ] 图像是否归一化？（0–255 vs 0–1）
- [ ] 边界是否处理？（图像边缘的卷积/插值）
- [ ] 参数单位对不对？（像素 vs 比例、毫秒 vs 秒）
