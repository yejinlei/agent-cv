## 1. 当时的问题

早期图像去噪多用简单均值滤波（盒子核），但均值核会把邻域一视同仁，导致图像出现方块状伪影，且不满足「距离越近权重越大」的直觉。

## 2. 核心思想

把概率论里的高斯分布搬到图像上：离中心越近的像素权重越高，权重曲线是钟形。这样一次平滑既去了噪，又最大限度保留了整体结构。

## 3. 关键贡献

- 提出用**可分离**方式实现二维高斯卷积：先横向一维卷积，再纵向一维卷积
- 证明二维高斯核可分解为两个一维高斯核的乘积
- 奠定了尺度空间理论（SIFT 的多尺度）的数学基础

## 4. 核心公式（看懂思路即可）

二维高斯核：G(x, y) = (1 / (2πσ²)) · exp(−(x² + y²) / (2σ²))。可分离性：G(x, y) = G(x) · G(y)，于是 O(W²) 的二维卷积变成两趟 O(W) 的一维卷积。

## 5. 实验结果

在含高斯噪声的测试图上，高斯滤波相比均值滤波显著减少了块状伪影；在 Canny 检测前置使用 σ=1.4 时，边缘定位误差最小。

## 6. 局限与争议

高斯滤波是**线性低通滤波**，不区分边缘与噪声——边缘同样被衰减。对脉冲（椒盐）噪声几乎无效。

## 7. 历史影响

它是尺度空间、SIFT、SURF、Canny、图像金字塔、LoG/DoG 等几乎所有经典多尺度方法的基石；深度学习时代的卷积神经网络（CNN）本质上也是可学习的高斯核推广。

## 8. 一句话总结

> 一个 1809 年的概率公式，成了 200 年后图像处理里出现频率最高的一行代码。
