# 第 7 页 · 调参口诀

## 一句话调参口诀

```
sigma 定模糊、ksize 定范围；ksize ≈ 6σ+1 取奇数；保边别用它。
```

## 参数速查表

| 参数 | 含义 | 推荐值 | 调大效果 | 调小效果 |
|------|------|--------|----------|----------|
| ksize | 核大小 | **(5,5)** | 更糊、更慢 | 更接近原图 |
| sigmaX | 模糊强度 σ | **1.0~2.0** | 模糊强、细节丢 | 去噪弱 |
| borderType | 边界模式 | **REPLICATE** | — | — |

## 实战技巧

### 和 Canny 搭配

Canny 内置高斯平滑，别重复做；若要更强去噪，可先手动高斯 σ=1.0，再调低 Canny 的 apertureSize。

### 和 SIFT 搭配

SIFT 内部用 σ=1.6 的高斯建尺度空间，自己预处理时不要超过这个值，否则特征点漂移。

### 估计 σ 的小技巧

用拉普拉斯方差的噪点估计法，或直接对平坦区域算局部标准差。

## 性能参考

| 条件 | 耗时 | 说明 |
|------|------|------|
| 640×480 灰度，ksize=5 | ≈0.6 ms | OpenCV 可分离卷积，单核 |
| 1920×1080 彩色，ksize=7 | ≈4 ms | 三通道分别处理 |
| 1920×1080 彩色，ksize=31 | ≈35 ms | 大核明显变慢 |

## 选型建议

**适合用**：拍照手抖模糊、人脸磨皮、Canny 去噪预处理、SIFT/SURF 尺度空间构建

**不适合用**：会把边缘一起糊掉，不能保边、对椒盐噪声无效、σ 太大丢失细节

::: tip 一句话
给图像戴一副老花镜——最常用的平滑去噪瑞士军刀
:::
