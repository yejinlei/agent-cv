# 第 6 页 · 踩坑清单

## 新手最常掉的坑

### 坑 1：核尺寸必须是奇数

::: danger 现象
传 (4,4) 会直接抛异常，OpenCV 要求正奇数。
:::

::: tip 解决
养成习惯：ksize = 2·r + 1，r 是想要的核半径。
:::

### 坑 2：sigmaX=0 不是不模糊

::: danger 现象
很多人以为 sigmaX=0 表示不做模糊，其实它表示「自动推导 σ」，模糊照样发生。
:::

::: tip 解决
想真的不处理就别调用，或者用 sigmaX=0 但 ksize=(1,1)。
:::

### 坑 3：把边缘一起糊掉了

::: danger 现象
高斯是线性低通，边缘和噪声一起被压。
:::

::: tip 解决
需要保边就换 cv2.bilateralFilter；需要保边又更快可用 cv2.medianBlur。
:::

### 坑 4：深色背景出现暗边

::: danger 现象
默认反射边界会令图像四边略暗。
:::

::: tip 解决
改用 cv2.BORDER_REPLICATE 复制边界像素。
:::

## 通用调试四步法

1. **可视化中间结果**——不要只盯最终输出，把每一步的中间图都存下来看
2. **先小图后大图**——拿 200×200 的简单图跑通，再上真实场景大图
3. **先默认值后调参**——有 baseline 再改，一次只改一个参数
4. **对齐参考实现**——用 OpenCV 官方 tutorial 的结果做基准，差异大就查原因

## 自查清单

- [ ] 数据类型对不对？（uint8 vs float32 差别巨大）
- [ ] 通道顺序对不对？（BGR vs RGB、灰度 vs 彩色）
- [ ] 图像是否归一化？（0–255 vs 0–1）
- [ ] 边界是否处理？（图像边缘的卷积/插值）
- [ ] 参数单位对不对？（像素 vs 比例、毫秒 vs 秒）
