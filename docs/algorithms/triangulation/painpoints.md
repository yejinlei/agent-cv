# 第 6 页 · 踩坑清单

## 新手最常掉的坑

### 坑 1：基线太小

::: danger 现象
两个相机几乎重合，深度误差爆炸，点云糊成一团。
:::

::: tip 解决
保证足够基线；纯旋转场景放弃三角化。
:::

### 坑 2：误匹配生成飞点

::: danger 现象
错误对应点三角化到很远的地方。
:::

::: tip 解决
先用 RANSAC 清匹配，三角化后再按重投影误差过滤。
:::

### 坑 3：不归一化直接 DLT

::: danger 现象
数值不稳定，结果抖动。
:::

::: tip 解决
先对像素坐标做归一化（Hartley 归一化）再求解。
:::

### 坑 4：忽略深度符号

::: danger 现象
三角化点跑到了相机背后。
:::

::: tip 解决
检查深度为正，负深度说明位姿有误。
:::

## 通用调试四步法

1. **可视化中间结果**——不要只盯最终输出，把每一步的中间图都存下来看
2. **先小图后大图**——拿 200×200 的简单图跑通，再上真实场景大图
3. **先默认值后调参**——有 baseline 再改，一次只改一个参数
4. **对齐参考实现**——用 OpenCV 官方 tutorial 的结果做基准，差异大就查原因

## 自查清单

- [ ] 数据类型对不对？（uint8 vs float32 差别巨大）
- [ ] 通道顺序对不对？（BGR vs RGB、灰度 vs 彩色）
- [ ] 图像是否归一化？（0–255 vs 0–1）
- [ ] 边界是否处理？（图像边缘的卷积/插值）
- [ ] 参数单位对不对？（像素 vs 比例、毫秒 vs 秒）
