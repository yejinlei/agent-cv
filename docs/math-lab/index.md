## 💡 学习建议

按照下面顺序玩，从最简单到最复杂，传统CV的数学基础就全懂了：

1. **像素矩阵** → 先搞懂"图像到底是什么"
2. **邻域与距离** → 为什么算法总说"周围3×3"
3. **卷积** → 90%传统算法的底层操作
4. **高斯分布** → 为什么"权重中间大周围小"
5. **梯度/边缘** → 边缘检测的数学本质
6. **阈值分割** → 最基础的"前景背景分离"
7. **形态学运算** → 二值图的"橡皮擦"
8. **直方图** → 怎么让暗图自动变亮
9. **颜色空间** → 为什么HSV做颜色分割更好
10. **Harris角点** → "什么是特征点"的数学定义
11. **霍夫变换** → 怎么从一堆点里找出直线/圆
12. **傅里叶频域** → 低频和高频到底是什么
13. **RANSAC** → 为什么它不怕错点/噪声
14. **Lucas-Kanade光流** → 怎么追踪物体移动
